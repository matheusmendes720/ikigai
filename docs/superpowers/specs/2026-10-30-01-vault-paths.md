# SPEC-01 — Um caminho, uma árvore

**Date:** 2026-10-30 · **Status:** proposed · **Depends on:** — · **Blocks:** 02, 03, 04

## Goal
Uma função canônica resolve qualquer data para o caminho do vault, e as 4 skills de cadence leem **notas que existem**.

## Por que agora
`cadence.py:77-93` aponta para `vault/daily/`, `vault/weekly/`, `vault/monthly/`, `vault/quarterly/`. **Nenhum existe.** O conteúdo real vive em `vault/ikigai/closing-2026/<NN>-q<N>-<YYYY>/`. `ikigai_daily.py:64` lê sempre `""` → a skill sempre sugere "Dia sem registro".

## Anti-padrão que este spec evita
O teste-tautologia: `test_m162_cadence_helpers.py:17` assevera que a *string* do caminho é `vault/daily/2026-09-29.md`. Passa para sempre, com o diretório inexistente. **Este spec troca asserção de string por asserção de comportamento.**

## Decisões
- **D1** — Árvore canônica = `vault/ikigai/closing-2026/`. Alternativa (mover para `vault/daily/`) quebraria toda referência em docs/specs/plano ativo.
- **D2** — Trimestre resolvido por **glob**, não cálculo. O prefixo real é ordinal de pastas existentes (Q3-2026 = `01-`, porque Q1/Q2 nunca existiram). Calcular o ordinal quebraria quando Q1-2026 aparecer. Resolver por `*-q{N}-{YYYY}` é estável.
- **D3** — `monthly_path`/`quarterly_path` **não persistem**. Rollup é derivado; não há tier na árvore PAE de 5 níveis. As 2 skills passam a Proposal **read-only**.
- **D4** — `vault/daily/` etc. saem do código. Nenhum arquivo migrado (não existem).

## Contrato
```python
# src/contracts/vault_paths.py
# VAULT_ROOT e ancorado na raiz do repo, NUNCA no CWD. "vault/" relativo ao CWD
# resolve para nada quando o comando roda de outro diretorio, e essa e a convencao
# mais fraca das tres que coexistem no repo. Idioma canonico: sync_cli.py:56-57.
_REPO_ROOT = Path(__file__).resolve().parents[2]      # life/
DEFAULT_VAULT_ROOT = _REPO_ROOT / "vault"

def vault_root() -> Path:
    return DEFAULT_VAULT_ROOT

def closing_root(root: Path | None = None) -> Path:
    return (root or vault_root()) / "ikigai" / "closing-2026"

def quarter_label(d: date) -> str:      # "Q4-2026"
def quarter_dir(d: date, root: Path | None = None) -> Path:
    pat = f"*-q{(d.month - 1) // 3 + 1}-{d.year}"
    closing = closing_root(root)
    hits = sorted(p for p in closing.glob(pat) if p.is_dir())
    if not hits:
        raise FileNotFoundError(f"no vault dir for {quarter_label(d)} under {closing}")
    return hits[-1]

def daily_path(d: date, root: Path | None = None) -> Path:
    return quarter_dir(d, root) / "04-relatórios-diários" / f"{d.isoformat()}.md"

def weekly_path(d: date, root: Path | None = None) -> Path:
    iso = d.isocalendar()
    return quarter_dir(d, root) / "03-revisões-semanais" / f"{iso.year}-W{iso.week:02d}.md"

def quarter_path(d: date, root: Path | None = None) -> Path:
    return quarter_dir(d, root) / "01-plano-trimestral" / f"{d.year}-Q{(d.month - 1) // 3 + 1}.md"

def wave_dirs(d: date, root: Path | None = None) -> list[Path]: ...   # 02-onda-* ordenados
def all_notes(d: date, root: Path | None = None) -> list[Path]: ...   # 04-relatórios-diários/*.md ordenados
```

`root` existe para os testes apontarem para um tmp tree. Nenhuma função depende de CWD.
