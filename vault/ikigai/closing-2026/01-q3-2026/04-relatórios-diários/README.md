# Daily Reports — Q3-2026

## Pattern

One file per working day, named `YYYY-MM-DD.md`. Use the template
`vibe-ops/planning/_templates_periodos_v2/05-relatorio-diario.md`.

Each report takes **~10–15 minutes** and is done at end-of-day or first thing next morning.

Skip weekends. On weeks with holidays, skip those days too.

## Expected count

~**66 working days** across 13 weeks (Mon–Fri × 13 = 65, plus 1 buffer).

## Aggregation

Friday's reports feed directly into that week's `../03-revisões-semanais/YYYY-Www.md` review.

Suggested loop:

1. Write `2026-MM-DD.md` after each workday.
2. On Friday, skim all 5 reports.
3. Write `../03-revisões-semanais/2026-Www.md` aggregating the week.
4. Carry open items into next Monday's report.
