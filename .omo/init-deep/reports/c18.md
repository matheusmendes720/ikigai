## CONVENTIONS

- **Dual namespaces coexist.** `sys_ikigai` is imported as a bare namespace while canonical contracts/mesh are imported through dotted `src.*`; `interfaces.*` consumes both. Several modules bootstrap `sys.path` at runtime for standalone launches.
- **Plan aliases are intentional legacy adapters.** `sys_ikigai/entities/plan/*.py` are one-line shims to `src.contracts`; new code should use canonical contracts directly.
- **Pydantic v2 is dominant.** Canonical entity/security models use `ConfigDict`; most are frozen and forbid extras. `PlanEntity` deliberately differs: mutable, assignment-validated, and `extra="allow"` for forward compatibility.
- **Append-only and atomic persistence dominate.** Vault/audit/review-queue writes use append or temp-file+replace. SQLite triggers prohibit update/delete, with explicit archival/upsert mechanics as exceptions.
- **CLI conventions:** Typer command groups (`vector`, `profile`, `plan`, `regime`, `phase`, `sync`) with a root `--json` option; algorithm math commands are retained as archived stubs.
- **State machines:** dataclass transitions, callable guards, in-memory audit records, and factories named `<entity>_state_machine`. `_sm_base.py` must remain dependency-free from siblings.
- **Interfaces:** Studio is a FastAPI app factory plus vanilla HTML/CSS; operator is a Textual app with a `.tcss` stylesheet and filesystem-derived rows.
- **Gateway clients:** one factory per fork, all returning `StdioAdapter`; default call timeouts differ (taskdog 10s, CLI/tuiboard 15s, solverforge-calendar 60s).
- **Layout/naming deviations:** `gateway/adapters` contains both hyphenated legacy filenames and underscore aliases, with several duplicate stubs; `Project` also aliases Portuguese `Projeto`, explicitly distinguished from another project contract.
- **Parallel model families coexist:** `UEID`, `ScoreValue`, `EntityType`, and `StatusType` exist in both legacy `sys_ikigai.types`/enums and canonical entity modules. `sys_ikigai.types.UEID` is a legacy 5-part implementation; `sys_ikigai.entities.ueid.UEID` delegates to the canonical 4-part pattern while accepting legacy fixtures.
- **Documentation drift is material.** `interfaces/tui/README.md` marks its older user-facing framing superseded; `interfaces/tui/operator/README.md` still describes 3 tabs while code/tests implement 5. The operator adapter registry is an acknowledged structural copy of `interfaces.cli.server` rather than a shared import.

## ANTI-PATTERNS

Declared prohibitions and deprecated paths:

- **Never bypass the vault-write wrapper.** Every `vault_write` call must traverse `vault_write_wrapper`; the wrapper must not duplicate canonical audit logic. Agent SONHO phase transitions require `actor="user"`; only the documented `LEGAL_CALLERS` may bypass that restriction.
- **Do not implement algorithm math in this CLI/agent layer.** Vector scoring, meta-vector, regime, and phase heuristics are archived stubs and raise `NotImplementedError`; use the canonical algorithm packages.
- **Never deserialize raw pickle checkpoints.** `CheckpointAdapter` requires JSON-safe base64 envelopes and the LangGraph `JsonPlusSerializer`.
- **Do not manually edit generated `triagem.md`;** the next drift scan overwrites it. Kill-switch audit logs are append-only, and audit-log failure must not prevent kill-switch firing.
- **Do not use the deprecated `IKIGAiRecordBridge`;** call `SQLiteAdapter.upsert_ikigai_record()` directly.
- **Do not assume all gateway adapters are implemented.** Only taskdog delegates to the real mesh adapter; the other gateway-adapter modules return stub payloads, and taskdog supports only `taskdog_list_tasks` and `taskdog_create_task`.
- **Do not import sibling modules from `_sm_base.py`;** that would recreate the state-machine import cycle.
- **Do not mutate state from the operator TUI** is the stated invariant, yet the KillSwitch tab shells out to pause/resume commands and the README describes the whole TUI as never writing anywhere. Treat this as a documented/runtime contradiction, not a safe pattern.

Observed error-handling anti-patterns to avoid: CLI sync silently skips per-entity exceptions; TUI subprocess launch failures are swallowed; malformed task/queue records are skipped without surfacing counts. These can conceal partial failures.

## HOTSPOTS

- **Files over 500 lines:** `sys_ikigai/cli/app.py` (563) and `sys_ikigai/propagation/sqlite_adapter.py` (517). The largest logical units are Studio `server.py` (~456), vault wrapper (~438), and operator `app.py` (~436).
- **Structural branch-score concentrations** (AST branch metric, not a standard cyclomatic tool): `frontmatter.coerce_typed_values` 21; `studio.create_app` 18; `vault_write_wrapper.make_wrapped_vault_write` 16; `SQLiteAdapter.upsert` 16; `PlanEntity.to_frontmatter_dict` 16; nested `wrapped` 15; `upsert_ikigai_record`/`insert` 13; `MarkdownDB.query` 12; CLI `sync_run` 11.
- **Transition machinery is the central reference hotspot:** 8 factories create 55 `Transition` objects and 54 `add_transition` calls; changes to `_sm_base` or `_registry` fan out across every state-machine module.
- **Static name/coupling mismatch:** `MarkdownDB.read` imports `DeliverableEntity`, `DreamEntity`, `GoalEntity`, `ObjectiveEntity`, `ProjectEntity`, and `TaskEntity`, but the scoped plan shims export only `Deliverable`, `Dream`, `Goal`, `Objective`, `Project`, and `Task`. Resolve this before relying on `MarkdownDB.read` dispatch.
- **Identity-model split:** `PlanEntity` uses the legacy 5-part `sys_ikigai.types.UEID`, while `IKIGAiRecord` uses the canonical entity UEID. Passing IDs across both model families requires deliberate validation.
- **Append-only wording needs nuance:** `SQLiteAdapter.upsert` temporarily drops no-delete/no-update triggers, physically deletes an existing row, then reinserts it; archival similarly permits one update.
- **Gateway adapter directory is mostly duplication/stubs;** the real taskdog path reaches `src.mesh.adapters.taskdog`, while CLI/solverforge/tuiboard variants remain placeholders.
