## CONVENTIONS

Deviations from stack defaults, observed in code:

1. **Dual import identity is deliberate and inconsistent across the chunk.** `sys_ikigai/vault/task_io.py` imports `from contracts.task_change import ...` (bare), while `sys_ikigai/vault/sync.py` imports `from src.mesh import queue  # M59 dual-identity fix` and `interfaces/cli/read_tasks.py` imports `from src.contracts.common import UEID`. `tests/conftest.py` documents that `mesh` and `src.mesh` resolve to **two distinct module instances** of the same files, so monkeypatching must target both. Any patch here must cover both identities.
2. **Circular-import discipline in `interfaces/cli/v2.py`**: every `register_*(app)` takes the Typer instance as a parameter instead of using `@app.command()` at module top level, and `Proposal` / `make_meta_plan_subgraph` / `execute_proposal` are imported **inside** function bodies. The module docstring marks this "Pattern preserved (NOT refactored)" and warns that moving the lazy imports to module level reintroduces the Plan D Task E.1 cycle (`agents.v2.subgraph` ↔ `agents.v2.nodes.proposal_executor` ↔ `interfaces.cli.v2`).
3. **`sys.path` bootstraps live in four places** and their order matters: `interfaces/cli/__init__.py` (must run *before* sibling imports — pytest loads it while resolving the test package chain, before `conftest.py`), `interfaces/cli/tests/conftest.py` (also appends `<repo>/src/ikigai/src` for the `agents`/`mcp_server`/`observability`/`strategics` siblings), `interfaces/cli/mcp_runtime.py::_ensure_ikigai_src_on_path`, and `interfaces/cli/v2.py`.
4. **Local mypy config instead of the repo-root `mypy.ini`.** `interfaces/cli/pyproject.toml` sets `namespace_packages = true`, `mypy_path = ["../.."]`, `exclude = ['^__main__\.py$']`, `follow_imports = "skip"` for `interfaces.cli.*` and `"silent"` for `src.*`. Rationale in-file: the root config's `explicit_package_bases = True` makes the same file discoverable under two module names.
5. **Ruff config is package-local**: `line-length = 100`, `select = ["E","F","W","I","N","UP","B","A","C4","PT","RUF"]`, `ignore = ["E501"]`, `known-first-party = ["interfaces"]`; per-file ignores `E402` for `read_tasks.py` (deferred mesh imports after the Typer app) and `E402,F841` for `tests/*.py`.
6. **Output-mode convention**: interfaces use a `--json` flag (Typer `typer.Option(False, "--json")` + `console.print_json`). The gateway CLIs instead use a **mutually exclusive `--json` / `--human` pair** with TTY auto-detection (`_wants_human`: `--json` wins, else `--human`, else `sys.stdout.isatty()`), so piped output is JSON by default.
7. **Atomic-write pattern** (repeatable across `vault_write.py` and `sync.py::save_state`): `tempfile.mkstemp` in the **same directory** → write → `flush` → `os.fsync` → `os.replace`. `Path.rename()` is deliberately avoided (raises `FileExistsError` on Windows when the target exists).
8. **Cross-platform locking**: `sys_ikigai/vault/lock.py` uses `msvcrt.locking` on `sys.platform == "win32"` and `fcntl.flock` otherwise; releases on both normal exit and exception.
9. **Gateway is stdlib-only** — `http.server` / `socketserver` / `threading` / `queue`; explicitly no starlette/fastapi ("CI does not require them"). JSON-RPC 2.0 is hand-rolled with `Content-Length` framing; `stdio_server_base.serve_forever` reads `sys.stdin.buffer` in **binary mode** because text-mode `readline()` hangs on Windows subprocess pipes.
10. **Windows-aware platform branching**: `server.py::_is_pid_alive` uses `sys.platform == "win32"` (not `os.name == "nt"`) so mypy narrows `ctypes.windll`; process stop uses `taskkill /PID /T /F` on Windows and `SIGTERM` on POSIX.
11. **Stable ordering** for machine-readable output: `list_adapters()` returns `sorted(ADAPTER_REGISTRY)`, `adapter_names()` returns `sorted(...)`.
12. **Exit-code constants** in `kill_switch.py`: `EXIT_OK=0`, `EXIT_ACTIVE_OR_REFUSED=1`, `EXIT_CONFIRM_REQUIRED=2`, `EXIT_REASON_REQUIRED=3`.
13. **Comment/annotation style**: `from __future__ import annotations` in all 42 modules that have imports; module docstrings carry rationale plus a task/ADR identifier (`M72`, `M72.1`, `B3.4`, `W5.3`, `V5-F`, `R1.1`, `RT-03`, `D1–D5`, `SPEC D8/I9`).
14. **Unicode emoji in CLI output** (`✅ ⬜ ⚠️ ❌`), with `# noqa: RUF001` on the ambiguous ones.
15. **`interfaces/cli` does not declare `src/ikigai` as a dependency** (Poetry layout `src/ikigai/src/...` is not uv-installable). Consequence, spelled out in `pyproject.toml`: *every* third-party package imported at module level by `src.ikigai.src.agents.v2` / `src.ikigai.src.mcp_server` must be declared in `interfaces/cli/pyproject.toml` or a clean `uv sync` produces `ModuleNotFoundError`.
16. `pytest.ini` (package-local): `testpaths = tests`, `--strict-markers --strict-config`, `--basetemp=.pytest-tmp` (avoids the Windows `PermissionError` on a locked `%TEMP%\pytest-of-<user>`), markers `unit` / `integration` / `e2e`.

## ANTI-PATTERNS

- **Interfaces never write `vault/`.** `interfaces/cli/__init__.py` invariants: read-only on `vault/`; all writes go to `data/` (mesh queue + append-only jsonl); zero LLM in the path.
- **`vault_write` is the ONLY vault writer** (attribution report §7). All vault writes (deep agent, native CLI, forks) MUST go through it. It rejects: absolute paths, paths resolving outside `vault_root`, empty body + empty frontmatter, and an `actor` outside `{"user","agent","system"}`.
- `vault_read` never writes; it mirrors `vault_write`'s path-traversal guard and uses the same `VaultLock`.
- **The CLI must never programmatically set the kill switch** — "R5/R11 forbid it". Activation lives only in `sys_ikigai/security/kill_switch.py`; `interfaces/cli/kill_switch.py` is a pure consumer and adds **no new schema in `src/contracts/`, no new constants in `algorithm_constants.json`, and no new drift invariant**.
- **`TaskRecord` (`sys_ikigai/vault/sync.py`) is deprecated** — fires `DeprecationWarning` on construction (Pydantic `model_post_init`). New plan-output code must use canonical `contracts.Task` (`src/contracts/task.py`).
- **`task_io._write_tasks_to_data` must not keep a parallel `open("a")` writer** (R1.1) — it is a thin shim delegating to `CliAdapter.apply_change`, which owns the unified 14-field schema and the cross-platform lock.
- **Do NOT `import frontmatter`** for loads/dumps/Post — upstream 3.x dropped those APIs. Use the `frontmatter_compat` shim (PyYAML) or manual `yaml.safe_dump`. `vault_write.py` was rewritten on manual YAML for exactly this reason.
- **Lazy imports in `v2.py` MUST stay inside function bodies.**
- **`EventLog` NEVER deletes events** — append-only; rotation renames the active file aside (`.1`, `.2`) and keeps the bytes.
- **Gateway has no auth** by decision (`spec §10`, Q3=a): "no auth (localhost-only is sufficient)". Bind to `127.0.0.1` by default.
- **Audit-log write failure must NOT fail the vault write** (the write already succeeded) — `vault_write.py` swallows that exception.
- **`sync_cli --dry-run` must DO NOT push to taskdog or save state**; `reverse --dry-run` must DO NOT enqueue a `TaskChange` or save state.
- **`interfaces/cli` must not declare `src/ikigai` as a dependency**; and every module-level third-party import of `src.ikigai` must be mirrored in `interfaces/cli/pyproject.toml`.
- **typer >= 0.21 vendors Click as `typer._click`** — `typer.Exit` is NOT a subclass of `click.exceptions.Exit`; assertions must use `typer.Exit`.
- **`mcp` is pinned `<2`** — mcp 2.x removed `mcp.server.fastmcp` (renamed `mcp.server.mcpserver.MCPServer`).
- **`agent_consumer` and `agent_propagator` are NOT standalone processes** — they run inside `review_queue_worker`; `life server start/stop agent_consumer` must not spawn a process.
- **Spec-only adapters always report `exists=True`** (`a2ui` has no storage path; its metadata points at the design spec).
- `plan-add` / `plan-list` wrappers carry **zero policy engine / QHE / scoring imports** (explicit user constraint, 2026-08-29).
- `invoke_skill` post-processing must **not overwrite** a field already set by the post-processor.
