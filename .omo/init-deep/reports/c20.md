## CONVENTIONS

Deviations from stack defaults (repo-specific, load-bearing):
1. **Package isolation.** The repo root is *not* a package; every check runs inside the owning
   package's own env with its own mypy/Ruff config. `PackageSpec` "mirrors `.github/workflows/ci.yml`
   exactly" — still true: the `quality-gates` matrix contains exactly ikigai, vibe-ops, interfaces-cli,
   src-contracts, src-mesh.
2. **Pinned Ruff policy for the root bucket** (`CANONICAL_SELECT="E,F,W,I,N,UP,B,A,C4,PT,RUF"`,
   `IGNORE=E501`, line-length 100, `py311`) because Ruff 0.16 changed its default rule set.
3. **Diff attribution.** Only findings on lines the diff *added* fail; pre-existing debt is reported
   separately and never blocks the change.
4. **Env hygiene.** `run()` strips `PYTHONPATH`/`PYTHONHOME`/`MYPYPATH` from the inherited environment
   before applying the package env (prevents a foreign `pydantic_core` shadowing the package's).
5. **Windows tool resolution.** `tool()` prefers `~/.local/bin/<name>.exe` on `nt` (WSL `uv`/`poetry`
   on PATH cannot drive native Windows venvs); resolved lazily so a missing manager is *reported*, not fatal.
6. **`uv run --frozen`** for the root bucket — a review must never rewrite a lockfile.
7. **Smoke isolation.** Smoke scripts rebind module-level paths (`cli_mod.TASKS_JSONL`,
   `taskdog_mod.TASKDOG_DB`, `solforge_mod.UPI_DB`, `queue_mod.QUEUE_DIR`) to a `tempfile.mkdtemp()` dir
   and `shutil.rmtree` in `finally`; production `data/` is never touched.
8. **`python -c "exec(open(...).read())"`** for embedded drivers so `sys.path[0]` is the repo root
   (Windows Python refuses to resolve the `src` namespace package from a temp dir).
9. **Shell/batch parity** for `phase3_v1`: the `.bat` generator avoids `$`, `'` and unescaped parens;
   the `.sh` uses `cygpath` for native Windows paths.
10. **Help system.** `th`/`thq` always exit 0 (chaining allowed); UTF-8 via `LC_ALL/LANG=C.UTF-8`;
    TTY detection strips ANSI when piped; `TASK_HELP_FORCE_COLORS=1` forces colors for WSL→PowerShell
    interop; 100-char width cap; `__H2_SECTION_BREAK__` marker between H2 sections for the PS splitter.
11. **Help content layout.** Numbered topic files `00-12`, `-quick` variants, "Related Topics" footers,
    Portuguese domain terms (Sonho→Objetivo→Meta→Tarefa→Atividade), 5-level hierarchy emulated over
    Taskwarrior's flat Project→Task (Projects for Sonho, UDAs for the rest).
12. **Taskwarrior domain set** (from in-scope docs): UDAs `sonho_id, objetivo_id, objetivo_trimestre,
    meta_ciclo, tarefa_microciclo, bloco_tempo, ciclo, onda_numero, taxa_conclusao, barreira,
    teste_fogo_dimensao`; reports `narrativa, relatorios, revisao, supervisao, blocos, sonho, objetivo,
    meta, tarefa`; contexts `work, focus_today, week, review, ciclo, onda, teste_fogo, none`.
13. Both formatters mutate module globals (`global RESET, BOLD, … = ''`) to disable ANSI when not a
    TTY — deliberate, but a deviation from pure-function style.
14. Shebangs differ by tree: `#!/usr/bin/env python3` (`.github/scripts`, help) vs
    `#!/usr/bin/env python` (`scripts/smoke`).

## ANTI-PATTERNS

Explicit prohibitions found in scope:
- "review must never rewrite a lock" → `uv run --frozen`.
- "Variables that must never be inherited from the reviewer's own process" → PYTHONPATH/PYTHONHOME/MYPYPATH.
- "the review job must not fail on import when a manager is absent — it has to report which environment is missing".
- "an error on an untouched line is pre-existing debt and must not be used to block the pull request".
- "a run that could not be parsed did not measure anything" → unparsable mypy output = FAIL, not PASS.
- "pytest collected no tests — nothing was verified" → rc=5 / "no tests ran" = FAIL.
- "mypy MUST NOT be invoked with a path here" (ci.yml, echoed by `check_mypy`: the package's canonical
  target is authoritative; a path invocation gives Ikigai a second module identity).
- "Only function-local names are inspected … flagging them here produced 52 false positives";
  "Only the tail is inspected: the pytest summary comes last".
- Docs: "Always set `meta_ciclo` when using `+revisao` tag"; "Required when using `+revisao` tag
  (validated by on-add hook)"; "Don't overload any single block"; "Don't optimize for single metric";
  "Always return exit code 0 for help".
- Smoke rules: "Isolated: uses tmp_path; does NOT touch production data/";
  "Zero policy engine / QHE / scoring imports; Pure filesystem + SQLite; no LLM".
