## CONVENTIONS

Deviations from Python/pytest defaults — these are the rules a contributor must follow here.

1. **Milestone-tagged filenames.** 30/48 test files are `test_m<NNN>_<topic>.py`, named after the milestone ticket rather than the module under test. Adding a feature normally means adding a *new* `test_mNNN_*` file, not extending the existing `test_<module>.py`.
2. **Hand-rolled `sys.path` bootstrap, per file.** 32/47 `.py` files repeat `REPO_ROOT = Path(__file__).resolve().parent.parent` + `sys.path.insert(0, str(REPO_ROOT))`, and put `# noqa: E402` on every import placed after the insert. `conftest.py` does the same thing once, centrally — the per-file copies are duplicated, not shared.
3. **`REPO_ROOT` is computed four different ways**: `Path(__file__).resolve().parent.parent` (38 files), `Path(__file__).resolve().parents[1]` (`test_m147`, `test_m148`), `Path(__file__).parent.parent` (unresolved, `conftest.py`), `os.path.abspath(os.path.join(...))` (`test_langgraph_cli_smoke.py`), and an upward walk for `.claude/loop/constitution.md` (`test_loop_infra.py`).
4. **`from __future__ import annotations`** in 46/47 `.py` files (absent only in `test_loop_infra.py`).
5. **`.claude/loop/` is not a package.** `mcp_bridge.py` / `mcp_runtime.py` are loaded by path with `importlib.util.spec_from_file_location` (8 files). The dir is deliberately outside the runtime import graph — do not add an `__init__.py` there.
6. **Two import namespaces coexist**: `src.*` / `sys_ikigai.*` (dotted, repo-root or `<repo>/src`) vs bare `tools.*` / `agents.*` / `interfaces.*` / `contracts.*` / `life.*`. `conftest.py` also aliases legacy `ikigai.*` -> `sys_ikigai.*` so drift tests that import the old path still resolve to the same module objects.
7. **CLI-under-test is called as a plain function returning an exit code**, not via `CliRunner`: e.g. `rc.main(rel_path="", line=1, expected="x", reason="r") == 2`. Only `test_life_task_cli.py` uses `typer.testing.CliRunner` (the `life` CLI). `test_m138_console_script.py` shells out to `.venv/Scripts/life.exe`.
8. **Module-scoped `bridge` fixture** (`test_m142/143/144/145/146/147/148`) resets `mod._server = None` before/after each test so a bound production server never leaks between cases.
9. **Hermetic by default**: `tmp_path` (28 files) + `monkeypatch` (22) + `capsys` (15). HTTP is faked at `urlopen` level; `ChatAnthropic` is mocked; no network in CI.
10. **LLM key detection is env-var based**: `ANTHROPIC_API_KEY` (24 refs), `CLAUDE_API_KEY` (12, hermes-agent proxy `sk-test-*`), `MINIMAX_API_KEY` (6), `IKIGAI_FAKE_LLM` (4), plus `ANTHROPIC_BASE_URL` / `ANTHROPIC_MODEL` / `IKIGAI_MODEL` / `IKIGAI_DEV_MODE` / `IKIGAI_DISABLE_OTEL` / `IKIGAI_DISABLE_MCP_TASKDOG`.
11. **Shell tests are standalone**, not pytest-collected: `tests/test_dispatch.sh`, `tests/test_cost_dashboard.sh` use `set -euo pipefail`, a `PASS`/`FAIL` counter, `ok()`/`fail()` helpers, a `mktemp -d` sandbox with `trap 'rm -rf' EXIT`, and exit 1 on any failure. They copy the production script into the sandbox so its `$(dirname "$0")/..` REPO_ROOT resolution lands on the sandbox.
12. **Per-milestone "acceptance #N" comment blocks** separate test sections (`# ---- Acceptance #2: ... ----`).
