## CONVENTIONS

- `src/mesh` CLIs use `argparse`, not Typer. Output is TTY-sensitive: human/table by default on a terminal, JSON/JSONL when piped; `--json` and `--human` are mutually exclusive and `--json` wins. `taskdog_chat` is the exception (ANSI REPL, no output-mode flags).
- `src/ikigai` is a separate Poetry project (`poetry-core`, Python `^3.11`) with its own `pyproject.toml`; `src/mesh` instead has a nested `ruff.toml`. Both Ruff configs target py311, use line length 100, select `E,F,W,I,N,UP,B,A,C4,PT,RUF`, and ignore E501.
- Modules are deliberately split to stay below a stated 500-line cap: optimizer vs optimizer strategies, and Gantt engine vs renderers. `taskdog_cli.py` is the major exception at 1,035 lines.
- Shared contracts use strict/frozen shapes: `taskdog_models` uses Pydantic v2 `frozen=True`, `extra="forbid"`; mesh value objects generally use frozen dataclasses. Boundary code converts SQLite JSON strings into typed lists.
- Filesystem queues are append-only and use atomic temp-write + replace, with fsync and retry/backoff for transient `OSError`/permission failures. Investigation records are frozen except allowed status transitions.
- Task lifecycle writes go through the review queue (`TaskChange` -> validate -> propagate -> ack). Dependency CRUD is a separate audited subsystem. `cli_cli`, `mesh_cli`, and `review_queue_cli` are read-only.
- Pure-function boundaries are explicit: Gantt does no I/O/DB/adapter access; optimizer strategies do not mutate inputs and treat dependencies as hard constraints; cross-fork reads are best-effort and additive.
- Import identity is mixed by design/necessity: both `contracts.*` and `src.contracts.*`, and both `src.mesh.*` and `mesh.*`, appear in scope. `run_mcp_server.py`, `ikigai.bat`, and `taskdog_chat._ensure_ikigai_path` manipulate `sys.path`/`PYTHONPATH` to control which package tree wins. Lazy imports break Gantt/optimizer cycles and keep CLI startup fast.
- UEID terminology is inconsistent: `SPEC.md` D10 and `README.md` call it a tri-key, mesh comments call the regex “4-part ADR-014”, while the regex and examples actually contain five colon-separated components; `taskdog_cli` expects `<cluster>:<entity>:<id>:<id>:<id>`.

## ANTI-PATTERNS

- Never commit real secrets: `.env` is gitignored; `.env.example` explicitly says `DO NOT commit real secrets` and requires rotating a previously leaked key before replacing placeholders.
- Keep Poetry dev tools in `[tool.poetry.group.dev.dependencies]`; moving them to PEP 735 `[dependency-groups]` silently removed pytest/ruff/mypy from the lockfile and CI.
- Do not reorder the deliberately deferred imports in `taskdog_mcp_graph.py`/`taskdog_tools.py`; import-time side effects are intentional. Do not add `files`/`modules` to the mypy config, and do not blanket-ignore `langchain_mcp_adapters` (it is typed and must be checked).
- `start_mcp_gateway.sh` is explicitly superseded/bit-rotted (missing Rust/Bun targets and WSL-only paths). It is preserved under the append-only invariant and must not be deleted; replacement is `python -m ikigai.gateway.start_gateway`.
- `td chat` must never auto-execute: always emit a proposal and wait for `--approve`.
- Reflection-log failures must not block task mutations; adapter failures must not crash propagation; vault writes are best-effort. Missing fork data is “not present”, not an exception.
- Do not resurrect terminal investigations (`resolved`/`archived` have no outgoing transitions). Notes are append-only; there is no update/delete note subcommand. Only investigation status transitions and the one same-ID overwrite are permitted edits.
- Queue/investigation files are written atomically; malformed queue files are logged and skipped rather than silently ignored.
