## CONVENTIONS

- Mixed import styles are intentional: relative `.reliability` / `.tools_taskdog` in tool modules; absolute `src.ikigai.src.agents...` in `taskdog_mcp_graph.py` and `paperclip/graph.py` (M102 absolute-import rule); top-level `agents.paperclip...` in `paperclip/cli.py`, which manually inserts `src/` and repo root into `sys.path`; `contracts.*` / `src.mesh.*` in `taskdog_mcp_graph.py`.
- `agents/__init__.py` extends `__path__` to merge the two top-level `agents` directories (`src/agents/` and `src/ikigai/src/agents/`) into one logical package, avoiding a `sys.path` race.
- Every scoped Python module uses `from __future__ import annotations` except `life_tatics/cli.py`.
- External-tool pattern: LangChain `@tool` wrapped by `@circuit_breaker(...)` then `@retry_with_backoff(...)`; retry defaults are 3 attempts, 0.5s initial backoff, 8s max, jitter, and breaker threshold 5 / 30s reset.
- Tool contracts are JSON strings with stable error envelopes; taskdog tools always parse `taskdog export --format json` and return `json.dumps(...)`, never raw stdout.
- `Paperclip` router models are Pydantic v2 strict (`frozen=True`, `extra="forbid"`); policy/router/persistence are leaf modules that import no Paperclip node or adapter, avoiding circular imports.
- LangGraph convention: public `make_<name>_graph(runtime, config)` factory plus internal `_build_<name>_graph`; state is a `TypedDict` whose fields are `NotRequired` and whose `messages` channel uses `Annotated[list[dict], operator.add]` (required by Cloud Studio chat detection).
- CLIs are Typer apps with `--json` on data commands; `paperclip` adds `--version` and `status`/`run`/`runs`/`spec` subcommands. `life_tatics/cli.py` emits JSON with `print(json.dumps(...))` instead of `typer.echo`.
- Gate semantics are deliberately asymmetric: cost and wall-clock gates are fail-open (missing/malformed data allows dispatch); the risk gate and router budget check are fail-closed (refuse on dangerous keyword match or budget overrun).
- Persistence writes one JSON snapshot per Paperclip run under `data/paperclip/runs/`, uses temp-file + `os.replace` atomic rename, sanitizes task IDs, and best-effort GCs beyond `MAX_RUNS = 100`.
- Harness filesystem access is sandboxed to `data/` and `vault/` roots; `strategics/` is a read-only constitutional layer.
- Temporal model: `life_tatics/time-lenghts_reviews.md` is the explicitly canonical version (behavioral days `D` vs calendar workdays `W`, `rho = 11/15`, WAVE 15D = 11W, CYCLE 45D = 33W, PHASE 180D = 132W, workdays rounded down and calendar days up). `planner/time-lenghts_reviews.md` is the earlier proportional variant (`WORK_RATIO = 22/30`). `SCALAR_DECOMPOSITION_BACKLOG.md` uses stable `MODEL-xxx` / `ENTITY-xxx` / `BL-xxx` identifiers and marks aspirational modules `PLANNED`. Docs mix PT-BR/English, use Obsidian frontmatter/wikilinks, and keep hyphenated filenames (including the misspelling `lenghts`).

## ANTI-PATTERNS

- Planner-only agent (ADR-013): do NOT bind math, policy, scoring, regime/phase, or business-rule tools to the IKIGAI agent; `IKIGAI_TOOLS` must stay at exactly 12 entries. Runtime taskdog MCP tools are appended separately and do not count.
- Read tools NEVER write: `ikigai_read_vault` and `ikigai_read_strategics` are read-only; never contradict or rewrite `strategics/`.
- `ikigai_write_vault` must NEVER auto-execute; it requires a user-approved agent invocation, rejects absolute paths and traversal, and logs `actor=agent`. Caveat: its `mode="update"` replaces the whole file even though the docstring calls the invariant "append-only" - treat update mode as destructive and do not bind it casually.
- `ikigai_sync_vault` and `_read_checkpoint_data` in `tools.py` are legacy/test shims: the sync writer is deliberately NOT registered in `IKIGAI_TOOLS`, and `_read_checkpoint_data` is a stub.
- Taskdog tool output must be structured JSON, never raw stdout; `taskdog_get_task` intentionally filters `export` output because the CLI `show` verb is broken.
- MCP loading must NEVER raise or block agent startup: `get_taskdog_tools()` returns `[]` with a warning on any failure; `IKIGAI_DISABLE_MCP_TASKDOG=1` is the CI escape hatch. Never overwrite an already-bound MCP bridge server, and never let bridge binding crash startup.
- Risk gate must NEVER silently empty the dangerous-keyword list; unset/empty `PAPERCLIP_RISK_KEYWORDS` falls back to the default list. An explicit empty list is a documented test-only escape hatch. Off-list adapter names are silently skipped by the router.
- Cost/wall-clock gates are guardrails, not security boundaries: malformed or missing data fails open with an explanatory reason. By contrast the router's budget gate is fail-closed and raises `CostThresholdExceeded`.
- Persistence failures must never mask the real graph outcome; the CLI persists best-effort and logs `persist_run failed (non-fatal)`.
- `paperclip spec validate` is a stub that always reports `"valid": true`; do not treat it as schema validation.
- Broad exception handling is intentional only at startup/REPL/persistence boundaries (logged, not silently swallowed); control-flow exceptions are re-raised.
- Temporal anti-bug rules from the canonical doc: ALWAYS declare units (`WAVE = 15 D`, never `WAVE = 15`); ALWAYS show base and converted columns side by side; discount real holidays before decisions; keep `BUFFER_CYCLE = 3 D`; NEVER assume automatic equivalence between CYCLE and HALF_QUARTER.
- The scalar backlog is append-only and partly aspirational; do not treat its `PLANNED` module/file map or legacy `business_logic/`, `decorators/`, `models/` paths as current architecture.
