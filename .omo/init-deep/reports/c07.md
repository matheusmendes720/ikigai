## CONVENTIONS

1. **Four import identities coexist** — `mcp_server.*` (bare), `src.contracts.*` (bare), `src.mesh.*` (dotted), `sys_ikigai.*` (bare), plus `agents.v2.*` in places. `resources.py`/`tools_mesh.py` carry `# M73.3 dual-identity fix` on `from src.mesh import queue as _queue`.
2. **MCP split** — `server.py` holds FastMCP + decorators only; logic bodies live in `handlers.py` / `tools_mesh.py` / `tools_vault.py` / `taskdog_tools.py`; `__init__.py` re-exports only the 3 investigation fns.
3. **Two FastMCP instances on purpose** — `ikigai-gateway` and `taskdog`, "separate so this module can be wired or registered independently (no cross-talk with ADR-013 canonical scope enforcement)".
4. **Handler return contract** — MCP handlers return JSON **strings**; errors as `{"error": ..., "code": -32601|-32602|-32603}`. Investigation tools return `dict`.
5. **CLI output mode** — `--json` wins → `--human` wins → TTY default (`_wants_human` duplicated in all 3 `td_*` modules).
6. **CLI wiring shape** — every `td_*` module exposes `register_<x>_subparser(sub)` + `run_<x>_command(args)`; `src/mesh/taskdog_cli.py` is the only caller.
7. **`argparse`, not Typer** — deviates from root AGENTS.md ("CLI: Typer sub-apps"); `--json` everywhere *is* honored.
8. **`from __future__ import annotations`** is universal in `src/ikigai/**` but absent in `src/mesh/adapters/{cli,base,solverforge_calendar}.py`.
9. **`Annotated[str, "..."]`** used for MCP tool param docs in `tools_mesh.py`/`tools_vault.py` only.
10. **Test-probe proxies** — `proposal_executor` exposes module-level `wrap_vault_write`/`taskdog_create_task` callables so tests can `patch(...)`; `nodes/commit.py` resolves `agents.tools` via `sys.modules.get(...)`.
11. **DB override by mutation** — `_apply_db_override` rewrites module-level `TASKDOG_DB` (repeated in `td_advanced`, `td_gantt`, `td_tag`, `taskdog_tools`); tests must monkeypatch both `src.*` and bare identities.
12. **Algorithm constants live only in JSON** — `prompts/algorithm_constants.json` is the single source of truth; `load_constants.get()` is the only accessor. `load_constants._defensive_default()` duplicates those values in Python as a fallback (a documented mirror, but it is still a Python copy of every tuning value).
13. **Pydantic strict** in `a2ui_schema.py`: `frozen=True, extra="forbid"`, matching `src/contracts/` (AGENTS.md).
14. **Paperclip tests live inside the package** (`agents/paperclip/tests/`), use `tmp_path` + `monkeypatch`, never shell out or touch git.

## ANTI-PATTERNS

- **ADR-013 planner-only.** `server.py` records the deletion of 7 `@MCP.tool` wrappers (ikigai_score/regime/phase/corrections/plan_cycle/checkpoint/sync_vault) and 2 inline handlers. 5 nodes (`balance`, `heuristics`, `plan`, `reflect`, `score_vectors`) are no-op stubs that write to `error_channel` instead of calling the bridge: *"If this node ever needs to come back, wire a real MCP bridge wrapper ... before re-introducing the call here."* 8 stub tools return `{"stub": True, ...}`.
- **Vault writes.** `vault_write` is the ONLY vault writer (ADR-012). `_handle_ikigai_sync_vault` "MUST NOT write to vault". `proposal_executor.vault_write` is a forbidden sentinel that raises `RuntimeError("proposal_executor MUST NOT call raw vault_write — route through wrap_vault_write (ADR-029, drift invariant n)")`.
- **Approval gate (drift invariant o).** `execute_proposal` asserts `proposal.approval_state == "approved"` before any write.
- **ADR-019 constants.** "algorithm tuning happens ONLY by editing prompts/algorithm_constants.json"; new Python `DEFAULT_*` constants in `agents/v2/*.py` are FORBIDDEN; drift detector `test_canonical_scope.py::test_no_algorithm_constants_in_agent_code`. `observe.md`: *"NEVER introduce new `DEFAULT_*` constants in `agents/v2/*.py`."*
- **Never hard-delete.** `td_advanced.py`: "Hard-deletion is NEVER performed"; `rm` = soft-delete (`status='deleted'`, audit_log preserved); `restore` is the inverse; `db restore` requires `--yes` and exits 2 without it.
- **All MCP writes go through the review queue** (ADR-014); drift test `test_taskdog_tools_read_only_contract` permits write tools only if they route through `_enqueue_task_change`. No direct SQLite writes from MCP.
- **Mesh v1 = create only.** `ikigai_task_create` returns `-32601` for any other action; `CliAdapter.apply_change` and `SolverforgeCalendarAdapter.apply_change` early-return unless `action == "create"`. **Divergence:** `TaskdogAdapter.apply_change` *does* implement `update`/`done`/`delete`/`tag_add`/`tag_remove`/`tag_clear` (M148/M163/M164), contradicting root AGENTS.md ("Phase 3 mesh v1 ships `create` action only").
- **Never auto-execute writes in nodes.** `dep_graph.py`, `gantt_suggest.py`, `tag_propagation.py`: "Per ADR-013: NEVER auto-execute writes"; they only compute a `proposal`.
- **Dead / historical code.** `observe.py` keeps `_build_agent_response` / `_read_workload_from_upi` behind `if False:` (references undefined `subprocess`/`json`); `heuristics.py` docstring records H1–H6 helpers removed 2026-09-21; `TODO(Phase 8.2): replace subprocess call with MCP tool wrapper`.
- **Fragile dispatch.** `tracing._dispatch_args` inspects the first parameter's *name* (`arguments`) and annotation string to pick dict-vs-kwargs protocol.
- **Gate polarity differs by design.** `CostGate` and `WallClockGate` fail-OPEN (missing/malformed file → allow); `RiskGate` is fail-CLOSED. Reason strings must contain the literal `"exceeds"` for log scrapers.
- **Kill-switch.** `execute_proposal` re-raises any exception whose class name contains `KillSwitch` before returning a partial report.
- **UEID regex drift risk.** `src/mesh/adapters/taskdog.py` inlines a *different, wider* UEID regex (`[a-z]{2,8}`, 3 alternatives) than `contracts.common.UEID` / AGENTS.md ADR-014 (`^[a-z]{2,5}:[a-z0-9-]+:[a-f0-9-]+:[a-f0-9-]+$`), with the comment "Kept inline to avoid a circular import".
- **Lint suppressions in-scope:** `# noqa: E402` (server.py, resources.py), `# noqa: F401, I001` (prompt shim import order), `# noqa: RUF001` (literal `×` in `td_gantt` help text).
