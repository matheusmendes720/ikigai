## CONVENTIONS

Deviations from plain-pytest defaults — all deliberate, all repeated:

1. **Self-bootstrapping `sys.path`.** 7 files mutate `sys.path` at import time (`sys.path.insert(0, str(...))`) so the file is runnable standalone (`pytest <file>`), not only via the repo `conftest.py`. Roots used: repo root (`REPO_ROOT`), repo `src/`, and `src/ikigai/src`.
2. **Four import roots coexist** in one suite: bare `agents.*` / `contracts.*` (10 + 1 files, needs `src/ikigai/src` on the path), dotted `src.agents.*` / `src.contracts.*` / `src.mesh.*`, `src.ikigai.src.*` (doubled prefix, 6 files — `from src.ikigai.src.agents.v2.state import IKIGAiStateDict`), and bare `sys_ikigai.*` (14 files). `test_meta_plan_integration.py` mixes `sys_ikigai.*` and `src.*` in one file.
3. **Path-anchor block** repeated verbatim in 8-10 files: `THIS_FILE = Path(__file__).resolve()` → `IKIGAI_TESTS = THIS_FILE.parent` → `IKIGAI_PKG = IKIGAI_TESTS.parent` → `IKIGAI_SRC = IKIGAI_PKG / "src"` → `REPO_ROOT = IKIGAI_PKG.parent.parent`. Comment says "mirror test_drift_extended_invariants.py".
4. **Static-AST drift tests instead of subprocesses** — `test_paperclip_drift.py` states the rule: "Follows the static-AST-walk pattern … rather than spawning subprocesses — keeps the drift net fast and avoids import-time side effects."
5. **Allowlist + justification pattern**: `SQLITE_ALLOWLIST: frozenset[str]` with a per-entry comment explaining why (retention pruning, read-only legacy reference copies).
6. **Optional deps never hard-fail**: `pytest.importorskip("starlette")` (5 uses), module-level `pytestmark = pytest.mark.skipif(...)` with a reason string, `pytest.skip("... not found: {path}")` when an optional source file is absent.
7. **Banner comments**: `# ---- 72-char rule ----` section dividers with numbered invariant blocks; invariant tests carry a docstring stating the rule and the failure message.
8. **Naming**: file `test_<subject>.py`; class `Test<Subject>`; function `test_<behavior>_<expected>`; helpers `_`-prefixed; fixtures named `<thing>_db` / `<thing>_dir` / `<thing>_queue`.
9. **Annotations**: `from __future__ import annotations` in 48/49 files; every test is annotated `-> None`.
10. **Env gating**: `IKIGAI_DISABLE_MCP_TASKDOG` (3 files), and `ANTHROPIC_API_KEY` / `MINIMAX_API_KEY` / `CLAUDE_API_KEY` presence checks before LLM-dependent paths.
11. **Isolation**: every DB/file test builds real SQLite/files under `tmp_path`; `test_recursive_reflection.py` notes the repo `conftest.py` redirects `tempfile` to `data/pytest-tmp/` to avoid Windows file locks.
12. **Monkeypatching targets production module attributes** (`src.mesh.queue.QUEUE_DIR`, `src.mesh.adapters.taskdog.TASKDOG_DB`, `mcp_server.tools_mesh._load_adapters`, `mcp_server.tracing._tracer`) rather than injecting dependencies.

## ANTI-PATTERNS

Hard prohibitions encoded as failing assertions (all enforced by tests in this chunk):

- **agents/v2/ must stay planner-only** — forbidden imports (`FORBIDDEN_IMPORTS`, 8 entries: `ikigai.core.scoring`, `ikigai.core.heuristics`, `ikigai.core`, `agents.ikigai_maintainer`, `src.agents.ikigai_maintainer`, `ikigai_scorer`, `cybernetics.daily_loop`, `vibe_ops.cybernetics.daily_loop`); forbidden function defs/calls (`FORBIDDEN_FUNCTIONS`, 16: `compute_meta_vector`, `compute_qhe`, `compute_score`, `compute_regime`, `compute_phase`, `compute_passion_score`, `compute_skill_score`, `compute_market_score`, `compute_revenue_score`, `compute_course_score`, `compute_alignment_label`, `compute_weighted_priority`, `rank_tasks`, `classify_opportunity`, `apply_hysteresis`); forbidden classes (`FORBIDDEN_CLASSES`, 6: `IkigaiScorer`, `QHEScorer`, `PassionScorer`, `RegimeClassifier`, `PhaseDetector`, `VectorScorer`).
- **`observe.py` must not re-introduce QHE/PAE math**: no `DEFAULT_*` module-level assignments, no raw `0.85` / `0.60` literals, no `prompts.load_constants` import, no `QHE` identifier. Algorithm constants live **only** in `src/ikigai/src/agents/v2/prompts/algorithm_constants.json` (violates W3.2 / ADR-019).
- **SQLite append-only in production layers**: no `DROP TABLE`/`DROP INDEX`, no `DELETE FROM`; `sqlite3.connect()` literal paths must be under `data/` or `:memory:` (runtime params exempt); schema changes require a migration script + allowlist entry with justification.
- **Taskdog MCP surface is read-only**: Path 3 exposes exactly 3 tools; any tool name containing `apply_change` or `write` is a violation; `apply_change` must not be reachable as a tool.
- **ReAct tool surface contract**: `_build_lc_tools()` returns `> 0` and exactly `len(taskdog_* wrappers) + 2`; every tool is a `StructuredTool` with non-empty `name`/`description`; names must start with `taskdog_` or `ikigai_` (no internal bridge helpers leak).
- **Reflection layer is LLM-free**: source of `src/agents/reflection/` must not contain the substrings `openai`, `anthropic`, `langchain`, `litellm`, `MiniMax`.
- **Vault writes go through the guard**: raw `vault_write` must never be called — use `wrap_vault_write` (kill-switch aborting on `KillSwitchAbort`).
- **Read-only nodes**: the daily skill and the v2 score/regime nodes must not write to `vault/`.
- **Legacy reference files unreachable**: live `agents/tools.py` must not reference `tools_legacy_reference` / `harness_legacy_reference`.
- **Pydantic models use `extra="forbidden"`**; `phase_weights` MUST NOT live on `IKIGAiRecord`.
- **Drift-count mechanic**: the invariant total is a count of `def test_X() -> None` functions (68 → 70 with the two paperclip tests); removing a drift test silently lowers the bar, so drift tests grow but are never deleted.
