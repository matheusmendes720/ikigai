## CONVENTIONS

- Three import identities coexist deliberately: root-level `sys_ikigai.*`, dotted `src.*`, and `agents.*` from `src/ikigai/src`. `conftest.py` also aliases legacy `ikigai.*` modules to the same `sys_ikigai.*` objects in `sys.modules` to prevent dual-module identity bugs.
- Import bootstrap must happen before pytest/project imports. Several files therefore mutate `sys.path` before imports and mark the import with `# noqa: E402`; `test_cross_session_memory.py` additionally reorders `sys.path` because two packages are named `agents`.
- 35/36 modules use `from __future__ import annotations`; `test_drift_state.py` is the sole exception.
- Drift protection is source-structural rather than only behavioral: AST walks detect forbidden imports/calls/classes, tool registrations, vault writers, queue mutations, and undeclared LangGraph state writes; regex/source checks supplement AST checks.
- Drift assertions are append-only. Do not weaken or delete them without an explicit ADR amendment.
- Isolation is fixture-driven: `tmp_path`, `monkeypatch`, and `capsys` dominate; local fake adapters and loopback HTTP servers avoid external services. `conftest.py` auto-isolates `src.mesh.queue.QUEUE_DIR` and disables the Taskdog HTTP bridge for every test.
- Windows receives special handling: temporary files are redirected to project-local `data/pytest-tmp/` to avoid locked shared pytest temp directories, while a few older tests still use `tempfile.TemporaryDirectory`/`mkdtemp` for the same reason.
- CLI tests generally assert both machine-readable JSON and human-readable behavior. Event-log and gateway-client CLIs treat `--json` and `--human` as mutually exclusive.
- `test_cli.py` and `test_ikigai_cli.py` are byte-for-byte duplicates; both cover `sys_ikigai.cli.app`.

## ANTI-PATTERNS

- ADR-013 planner-only boundary: production agent/MCP code must not import `ikigai.core.scoring`, `ikigai.core.heuristics`, `ikigai.core`, `agents.ikigai_maintainer`, `src.agents.ikigai_maintainer`, `ikigai_scorer`, `cybernetics.daily_loop`, or `vibe_ops.cybernetics.daily_loop`.
- Forbidden math/policy symbols include `compute_meta_vector`, `compute_qhe`, `compute_score`, `compute_regime`, `compute_phase`, `compute_passion_score`, `compute_skill_score`, `compute_market_score`, `compute_revenue_score`, `compute_course_score`, `compute_alignment_label`, `compute_weighted_priority`, `rank_tasks`, `classify_opportunity`, and `apply_hysteresis`; forbidden classes include `IkigaiScorer`, `QHEScorer`, `PassionScorer`, `RegimeClassifier`, `PhaseDetector`, and `VectorScorer`.
- Do not register the deleted MCP tools `ikigai_score`, `ikigai_regime`, `ikigai_phase`, `ikigai_corrections`, `ikigai_plan_cycle`, `ikigai_checkpoint`, or `ikigai_sync_vault`. `IKIGAI_TOOLS` must remain exactly 12 entries; adding or removing one requires an ADR-013 amendment.
- Algorithm tuning has one source of truth: `agents/v2/prompts/algorithm_constants.json`. Do not duplicate migrated `DEFAULT_*`/`HYSTERESIS_*` values as Python constants in agent code; consume the cached loader. Underscore-prefixed JSON keys are metadata and must not leak from the loader.
- Vault writes must use the guarded writer path. Only `mcp_server/tools_vault.py`, `ikigai/vault/vault_write.py`, and `ikigai/vault/__init__.py` are allowed to write vault files. Meta-plan nodes must never call `vault_write` directly; writes route `proposal_executor → wrap_vault_write` and require `approval_state == 'approved'`.
- `data/review_queue/` is append-only. Delete, rewrite, truncate, or `rmtree` operations are forbidden; normal writes go through `mesh.queue.enqueue()` (the worker has a narrowly defined acknowledgment exception in the canonical-scope detector).
- Taskdog MCP write tools must enqueue `TaskChange` through `_build_task_change`/`_enqueue_task_change`. They must not import `sqlite3` or call `execute`, `executemany`, `executescript`, `commit`, `apply_change`, or tag mutation APIs directly.
- The canonical UEID is four parts, `type:slug:uuid:hash`. No divergent five-part regex may exist. Pydantic shared models must remain `frozen=True` and `extra='forbid'`.
- `ikigai_serve` imports must be side-effect free; `bin/__main__.py` must delegate to `ikigai_serve.main`. Defaults are pinned to host `127.0.0.1` and port `8765`.
- `souls.loader.__all__` must equal exactly `{load_soul, known_profiles}`; profile names must be validated before filesystem access, and traversal such as `../etc/passwd` must be rejected.
- v2 graph state writes must be declared in `IKIGAiStateDict`/`MetaPlanStateDict`. The legacy undeclared-field allowlist is temporary and documents TODOs; new fields must not be added to it without review.
- `v2/graph.py` must not use relative imports; every `mcp_bridge.<attr>` referenced by a node must exist, every bridge wrapper must be registered by the MCP server, and every bridge wrapper must dispatch through `_call()` using its own name.
- Checkpoints must not use raw pickle. Path traversal in vault writes and cross-session session IDs must be rejected. `run_chat` must remain an orchestrator of at most 60 LOC.
- Archived CLI commands (`vector score`, `vector meta`, `regime status`, `phase status`, including their `--json` forms) must raise `NotImplementedError` rather than silently emulate removed behavior.
- The whole `test_ikigai_maintainer_nodes.py` module is skipped until the v2 maintainer graph is fully wired; this is an explicit tracked limitation, not an active smoke guarantee.
