## CONVENTIONS

Deviations from stack/repo defaults (deviations first, since they are the load-bearing facts):

1. **Two different UEIDs.** `vibe-ops/src/storage/ueid.py` builds a **3-part** id `<CLUSTER>:<ENTITY_TYPE>:<ID>` (`UEID.create`/`UEID.parse`), while the repo canonical contract (`src/contracts/common.py`, ADR-014) is a **4-part** regex `^[a-z]{2,5}:[a-z0-9-]+:[a-f0-9-]+:[a-f0-9-]+$`. `UEID` is referenced 669 times across 151 files repo-wide — the 3-part variant is the drift risk here.
2. **`from __future__ import annotations` in only 11/32 scoped Python files** (present in `bidirectional_sync.py`, `period_sync.py`, `dream_entities.py`, `hypothesis_entities.py`, `period_report.py`, `metadata_orm.py`, `sqlite_vec_integration.py`, both integration tests). Repo `AGENTS.md` says every module carries it — the `models/` majority does not.
3. **Pydantic models are mutable and permissive.** No `frozen=True` except `PeriodSyncStats`/`temporal_entities`; `extra="allow"` on `PeriodReport`, `Dream`, `FalsifiableHypothesis`, `HypothesisEvaluation`, `Project`, `StudyProject`. Repo contract rule for `src/contracts/` is `frozen=True, extra="forbid"` — vibe-ops deliberately relaxes it (`period_report.py:52` "Lenient mode (extra='allow') so user-added fields don't break validation").
4. **Mixed import styles**: absolute top-level (`from models.X import …`, `from middleware.X import …`, `from storage.X import …` — `vibe-ops/src` on `sys.path`) *and* relative (`from .orm import Base` inside `storage/`). Hyphenated dir name is documented in-code: `# noqa: N999 - package directory "vibe-ops" contains a hyphen and cannot be renamed`.
5. **Package init inconsistency**: `src/models/__init__.py` and `src/storage/__init__.py` exist; `src/middleware/` has **no** `__init__.py`.
6. **Idempotency is content-hash based.** Canonical JSON (`json.dumps(..., sort_keys=True, default=str)`) → `sha256` truncated to **12 chars** (`bidirectional_sync`, `sync_engine.compute_upstream_id`) or **16 chars** (`period_report.vault_hash`). Upserts use `ON CONFLICT … DO UPDATE … WHERE excluded.upstream_id != planning_entities.upstream_id`.
7. **Natural key beats hash for period reports**: `(sonho_id, period, date_start)`; `_fetch_existing` matches `id = ? OR vault_hash = ?`.
8. **D3 conflict policy** (`bidirectional_sync.py`): vault wins *manual* fields (`xp_*`, `mastery_*`, `subject`, `learning_phase`, `tech_stack`, `milestone`, `deliverable`, `commercial_goal`); code wins *computed* fields (`policy_state`, `rice_score`, `priority_rank`, `falsifiability_score`, `hypothesis_verdict`); ambiguous → appended to `.sync-conflicts.md` (markdown table, append-only).
9. **Append-only + atomic writes**: conflicts are appended; frontmatter writes go to `<file>.tmp` then `Path.replace()`.
10. **SQLite conventions**: raw `sqlite3` with `row_factory = sqlite3.Row`; `PRAGMA journal_mode=WAL` + `synchronous=NORMAL`; cross-process writes serialized with `BEGIN IMMEDIATE` (`advisory_lock`). SQLAlchemy 2.0 `DeclarativeBase`/`Mapped` is used *only* for the metadata catalog + state machine ORM; everything else is hand-written SQL.
11. **SQL naming**: tables `snake_case`; indexes `idx_<table>_<column>`; views `v_<entity>`; triggers `trg_<table>_updated`; migrations numbered `001…005`, each idempotent.
12. **Template convention** (`_templates_periodos_v2`): numbered `NN-name.md`, frontmatter starts `type: period_report` + `entity_type: period_report`, keys `period, id, template_role, template_version, ikigai_cluster, date_start, date_end, verdict, verdict_score, sonho_id, parent_period, ikigai_vector, ikigai_score_inicio/fim, vault_path, vault_hash, status, tags`; body = 8 numbered H2 sections. Verdict enums are per-period: daily/weekly/quarterly `PASS|PARTIAL|FAIL`, onda `CONTINUE_WAVE|CORRECT_TRAJECTORY|KILL_WAVE`, sonho `ACTIVE|VALIDATED|FALSIFIED|PIVOTED|ABANDONED`.
13. **Docs are Portuguese-first** (`doc/`, `vectors/`, `context/`); code comments/docstrings are English in `src/` and `tests/`.
14. `RELEASE-NOTES.md` declares the folder as the **source of truth** (mirror of `notas_estudo/_templates_periodos/`), synced bidirectionally; `vectors/README.md` states **append-only**.

- **Forbidden/absent in this chunk** (no occurrences found): `TODO`, `FIXME`, `HACK`, `XXX`, `DEPRECATED`, `PROHIBITED`, `FORBIDDEN`. No `AGENTS.md` present.
