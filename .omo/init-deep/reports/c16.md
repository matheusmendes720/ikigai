## CONVENTIONS

- Tests use behavior-oriented `test_<condition>` names, pytest fixtures, and `pytest.mark.parametrize` for UEID and literal validation matrices.
- Contract tests consistently pin Pydantic v2 behavior: frozen instances reject mutation, extra fields are forbidden, literals reject unknown values, and numeric/default/range rules are asserted explicitly.
- Import layout is mixed by architectural boundary: `src.contracts.*`, `src.mesh.*`, `src.tuiboard.*`, and `src.ikigai.*` use dotted paths; `sys_ikigai.*` is bare. `tests/ikigai/conftest.py` and the v2-local conftest prepend both repository root and `src/` because Windows pytest collection can otherwise import tests too early.
- Investigation fixtures patch both dotted and bare queue module identities because they are separate `sys.modules` entries with separate globals. Patching only one risks reading the real `data/investigation_queue/`.
- Isolation is the default: use `tmp_path`/`TemporaryDirectory`, monkeypatched module paths and environment variables, seeded temporary SQLite files, and no writes to real project data.
- Optional or external behavior is stubbed: Textual is skipped when absent; the fake LLM avoids model calls; Telegram credentials are cleared and fake credentials never authorize a real post; MCP-backed smoke tests accept an unavailable server only after parse/diff checks pass.
- Shell and Batch smoke tests are maintained as platform pairs. Shell scripts run from repository root, set strict/error modes, use `PYTHONPATH`, and clean temporary artifacts; Batch variants use Windows paths and explicit cleanup.
- Domain contract/module names remain Portuguese (`sonho`, `objetivo`, `projeto`, `tarefa`, `entrega`), while test and API names are generally English.
- UEID examples and the security-test comment consistently use four components, `type:slug:uuid:hash`. The names/docstring in `test_ueid_accepts_valid_5_part_format` incorrectly call this a five-part format and are stale wording.

## ANTI-PATTERNS

- The operator TUI must have no write paths or write bindings; it is an append-only/read-only interface. Queue drilldown must expose only dismissal/refresh-style actions.
- A SONHO phase transition requires `actor=user`; an agent actor is forbidden. Creation and same-phase checks intentionally skip transition validation, while lower hierarchy entities accept agent actors.
- Resolved and archived investigations are terminal: no further transition is allowed. Re-enqueue overwrite is the only permitted edit.
- An `open` investigation is never stale; malformed queue JSON must be skipped silently rather than crash the dispatcher.
- Never patch only one queue module identity; patch both dotted and bare imports or isolate can be bypassed.
- Vault writes must reject absolute/path-traversal targets and leave no `*.tmp` file after the atomic write.
- Telegram notification tests must not call the real API. MCP-unavailable smoke runs are valid only when CLI wiring plus parse/diff still succeed.
- MCP lifecycle tests call tool functions directly, not server-booted `@MCP.tool` wrappers. Gateway subprocess bind failure is treated as an environmental skip; an alive but unhealthy gateway is a failure.
- For duplicate UEIDs across adapters, Taskdog data has precedence over CLI data; the aggregator must return one Taskdog-backed row.
