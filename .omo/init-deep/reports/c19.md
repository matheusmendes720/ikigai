## CONVENTIONS

1. **Milestone-tagged module docstrings.** Every module opens `"""M<num> — <name>.py ..."""` (`M114a`–`M139`, `M163`–`M190`). The M-number is the tracker ID and is also used in inline comments (`# M120:`, `# M121:`), so history is traceable without git blame.
2. **`tools/backtest` has no `__init__.py`** — namespace package, no packaging metadata, no README, no config file. Cross-module imports must be absolute (`tools.backtest.*`) and require repo-root on `sys.path`.
3. **Flat CLI-per-tool layout.** Each module is a standalone `argparse` program with `main()`; most expose `--dry-run`; outputs are markdown/JSON files under `reports/`, not stdout-only. Subcommand style (`argparse` subparsers) is used only by `baseline_archive`, `baseline_integrity`, `baseline_sign`, `drift_baseline`, and `scripts/chat.py`.
4. **Bash style (M6/M7/M8 "pure bash + awk, no Python, no new dependencies").** `set -euo pipefail`; root resolved as `SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"` then `REPO_ROOT="$SCRIPT_DIR/.."`; **exit code 2 = "needs human intervention"** consumed by the notify channel without parsing files; output byte-identical across reruns except a `generated_at` line.
5. **Windows mirrors.** Each meaningful `.sh` has a `.bat` twin; the `.bat` twins set `PYTHONPATH` explicitly (`scripts/mcp-inspect.bat`: `%REPO_ROOT%;%REPO_ROOT%\src\ikigai\src`) because `make` is not on PATH in cmd/Windows Terminal.
6. **Two non-portable hardcoded absolute paths** (machine-specific by construction): `scripts/langgraph-dev.bat` (Python 3.13 `langgraph.exe` under the Windows-Store Python path, to dodge the Python 3.14 protobuf crash) and `scripts/ruvocal-start.bat` (`C:\Users\mathe\AppData\Roaming\npm\node_modules\ruflo\src\ruvocal`).
7. **`sys.path` bootstrapping before imports** (`chat_repl.py`, `paperclip-dashboard.py`, `mcp_probe.py`, `mcp_inspect.py`, `td`), which forces `# noqa: E402` on the late imports.
8. **Two competing HTTP servers on the same default port 8765**: FastAPI (`paperclip-dashboard.py`: `/api/health`, `/api/graph`, `/api/adapters`, `/api/gates`, `/api/runs`, `POST /api/invoke`) and stdlib `http.server` (`paperclip_heartbeat_http.py`: `POST /heartbeat`, Bearer auth). They collide if run simultaneously.
9. **Self-contained dashboards.** `paperclip-dashboard.py` embeds its whole UI as an in-file `HTML_PAGE` constant and degrades gracefully — a failed `src.ikigai` import is captured in `PAPERCLIP_IMPORT_ERROR` and surfaced in the UI instead of aborting startup.
10. **`from __future__ import annotations`** (repo-wide rule in AGENTS.md) is honored by 13/14 backtest modules and 9/10 script modules; the single exception is `scripts/m156_stub_pav.py`.
11. **Stale filename alias.** `tools/backtest/vault_propagation.py`'s docstring and CLI examples say `python tools/backtest/vault_diff.py` ("renamed semantically from vault_propagation.py") — `vault_diff.py` does not exist, so the documented command is stale.

## ANTI-PATTERNS

- **ADR-013 (planner-only) — PAV math must never execute.** `scripts/m156_stub_pav.py` rewrites 14 prompt render functions to `if True:  # M156: stub PAV-math, never real LLM`, preserving the real LLM body but never running it. `scripts/m158d_remove_m156_stubs.py` then removes those stubs (16 files) and `scripts/m158e_inject_anthropic_shim.py` injects `import agents.v2.langchain_anthropic_shim  # noqa: F401` before each `try:`. All three are **one-shot historical codemods** — not idempotent-guarded, no dry-run, they edit prompt files in place.
- **"Never abort the loop / never block the session."** `scripts/auto-start-loop-tick.sh`: "Always exits 0 — MUST NOT block session start"; a missing `daemon-manager.sh` is a silent no-op. `scripts/paperclip-spawner.sh`: "never crash the loop" (`sys.exit(0)` on unknown arg; unknown args are warnings, not errors).
- **Never write Python into the loop bash scripts.** `cost-dashboard.sh`, `notify.sh`, `streak-tracker.sh`, `worktree-helper.sh` are pure bash + awk/curl by spec (M6/M7/M8).
- **Never swallow a harness failure mid-corpus.** `backtest_harness.py`: `# noqa: BLE001 — harness must not abort mid-corpus` and `# best-effort, don't abort harness`.
- **Never flip an unrelated checkbox.** `vault_propagation.apply_toggle`/`apply_reopen` refuse when the target line does not match exactly ("safety: don't mistakenly flip unrelated checkboxes"); `INVARIANT_MARKER = "VAULT_WRITE_INVARIANT"` is the per algorithm-attribution §7 vault-write marker for the only code path allowed to mutate vault content outside explicit human edits.
- **No auto-trigger on `life task done`.** Vault is the SOT, taskdog is the operational timeline; vault updates are an explicit agent decision made during Routine Inicial/Final.
- **Never compare absolute drift counts.** `drift_regression.py`: "We do NOT compare absolute counts because drift baselines grow with the corpus"; regression = any drift kind growing >10% relative (configurable `--threshold`) or a new kind appearing 0 → >0; exit 1 on regression = CI gate.
- **Never let the LLM judge become mandatory.** `llm_judge.py` falls back to the deterministic stub when `IKIGAI_FAKE_LLM=1`, `ANTHROPIC_API_KEY` is unset, or the model raises ModelError/ConnectionError.
- **Never ship a real token.** `paperclip_heartbeat_http.py` default `HEARTBEAT_TOKEN="dev-token-do-not-use-in-prod"` (prod must override). `notify.sh`: the ntfy topic name **is** the auth secret — pick something unguessable (16+ chars).
- **Never grow the notify state file by cleanup.** `notify.sh` state is append-only and hash-deduplicated; periodic cleanup is explicitly out of scope.
- **Never assume a POSIX path on Windows.** `worktree-helper.sh` translates Cygwin `/c/Users/...` → `C:/Users/...` via `cygpath -m` before `git -C`, or `git -C` fails with "cannot change to …".
