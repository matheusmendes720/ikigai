## CONVENTIONS

Deviations from stack defaults (most are deliberate and drift-pinned):

1. **No Pydantic here.** All contracts are `typing.TypedDict` (`IKIGAiStateDict`, `SubAgentSpec`, `SubgraphLink`, `DailyIntentionRecord`, …) or plain `dataclass` (`Proposal`). This deviates from the repo-wide "Pydantic v2 strict, imported from `src/contracts/`" rule.
2. **Algorithm tuning constants are FORBIDDEN in Python.** All tuning lives in `src/ikigai/src/agents/v2/prompts/algorithm_constants.json`, read via `.prompts.load_constants.get` (ADR-019). New `DEFAULT_*` constants in `v2/*.py` are explicitly forbidden; drift test `test_canonical_scope.py::test_no_algorithm_constants_in_agent_code`. Identity/wire-format constants (`_UEID_REGEX`, `MEMORY_*`, `SCHEMA_CONTROL_KEYS`, `EVENT_TAXONOMY`, `MAX_REASON_LOOPS`, `TIER_DAYS`, `_EMBED_DIM`) remain legal in Python.
3. **Mixed import styles.** `graph.py` uses absolute `from src.ikigai.src.agents.v2.nodes.* import ...` (M102: so `langgraph_api` can load `graph.py` standalone without a parent package); the memory family uses relative `.memory_schema`; `subgraph.py` uses relative `.checkpoint` + `.prompts.load_constants`.
4. **Every module docstring cites its ADRs and the drift test that guards it** (ADR-012/013/014/019/025/026/027/028; `test_canonical_scope.py`, `test_v2_stateful_subgraph.py`).
5. **`from __future__ import annotations`** in 22/24 files — absent only in `__init__.py` (bootstrap shim) and the two `if False:` legacy files.
6. **`__all__` declared in 9/24** (checkpoint × 4, memory × 5). Absent in `graph.py`, `state.py`, `subgraph.py`, `sse_publisher.py`, `proposals.py`, `profile_switch.py`, `system_prompt.py`, `vault_cache.py`, `fork_smoke_graph.py`, `mcp_bridge.py`, `subagent_types.py`, `langchain_anthropic_shim.py`.
7. **Uniform error-channel convention.** Every graph node returns/reads `originating_node`, `error_type`, `error_message`, `traceback_str` (+ `error_traceback`, `commit_summary`). Nodes are wrapped by `_safe_node(name, fn)` (duplicated in `graph.py` and `fork_smoke_graph.py`) so exceptions become state, not crashes.
8. **All state fields are `NotRequired`** (OPEN-3 fix, 2026-10-02): the input schema must declare a `messages` field or Cloud Studio greys out chat input. `IKIGAiStateDict` and `ForkSmokeStateDict` both do.
9. **SQLite: fixed 4 PRAGMAs** — `journal_mode=WAL`, `synchronous=NORMAL`, `busy_timeout=5000`, `foreign_keys=ON` — applied in `checkpoint.py::_apply_pragmas` and `memory_schema.py::memory_init`, always with `check_same_thread=False`; `IkigaiCheckpointer` adds a `threading.RLock`.
10. **Three DB files**: `data/ikigai_checkpoints.db` (ADR-027 R1), `data/ikigai_memory.db` (ADR-028 R1, deliberately separate), `data/fork_smoke_checkpoints.db` (smoke only).
11. **Env vars**: `IKIGAI_CHECKPOINT_DB` (graph), `IKIGAI_FORK_SMOKE_CHECKPOINT_DB` (smoke graph), `IKIGAI_THREAD_ID` (legacy harness).
12. **Time**: `datetime.now(UTC)` / `datetime.now(timezone.utc)`; `datetime.utcnow()` is deliberately avoided (deprecated in 3.12+) — `checkpoint.py::_iso_utc_now` emits `%Y-%m-%dT%H:%M:%SZ`.
13. **Vault writes go only through `sys_ikigai.vault.vault_write`** (ADR-012) — `proposals.py::write_to_vault` and `memory_write.py::memory_write_atomic` both call it; no module writes `vault/` directly.
14. **Factory shim pattern (M102)**: every graph factory exposes a 0/1/2-arg `runtime/config` signature for `langgraph_api`, delegating to a `_build_*` function that keeps the original `(checkpoint_db, entry_point)` API.
15. **`vault_cache.py` avoids ChromaDB/numpy deliberately** (ChromaDB 0.5+ is broken on Python 3.14 + otel); embeddings are a deterministic local hash-based 384-dim pseudo-embedding, explicitly not semantic.

## ANTI-PATTERNS

- **`tools_legacy_reference.py` + `harness_legacy_reference.py`**: docstring "READ-ONLY legacy reference — DO NOT IMPORT". Whole body is wrapped in `if False:` so the drift detector does not see live `FunctionDef`/`Import`. `tools_legacy_reference.py` still carries `IKIGAI_TOOLS` (18 tools) and an `ikigai_plan_cycle` stub that returns `"[DEPRECATED] ikigai_plan_cycle removed from legacy reference per ADR-013"`. Never import these modules.
- **`__init__.py`**: "Do NOT import `sys_ikigai.core.scoring`, `ikigai.core.heuristics`, or `cybernetics.daily_loop`." The package is a READ-ONLY parallel branch; all math calls are prompt-chain stubs.
- **`state.py`**: `compute_meta_vector` is a **FORBIDDEN_FUNCTION** per ADR-013; the body is kept as a historical artifact and never executed.
- **`mcp_bridge.py`**: graph-facing wrappers **MUST be a subset of `server.py`'s `@MCP.tool` registry** (drift test `test_mcp_bridge_wrapped_tool_count_matches_canonical`). "Adding a new tool requires editing this file AND the drift detector … do NOT add silently." Errors propagate; the caller routes to `error_channel`.
- **`memory_migrations.py::_migrate_v1_to_v2`** **MUST raise `NotImplementedError`** until v2 ships — "Do not silently implement"; `apply_migrations` raises `NotImplementedError` for any undefined version transition.
- **`memory_write.py`**: strict append-only — **NO `INSERT OR REPLACE`** (ADR-028 R8). Raises `ValueError("append-only violation: …")` on PK conflict. `memory_write_atomic` performs vault_write + memory INSERT atomically, rolling back the vault file if the DB insert fails (ADR-028 R4).
- **`memory_schema.py`**: schema is **append-only** (CLAUDE.md §Refactor Protocol); ADR-012 `vault_write` is the sole writer; actor is CHECK-constrained to `('user','agent','system')`; `*_ueid` PKs must be 4-part UEIDs (ADR-014 R3) — 5-part UEIDs are rejected.
- **`subagent_types.py` / `subgraph.py`**: identity fields (`cycle_id`, `cycle_start`, `cycle_end`, `iteration`, `actor`) **ALWAYS** propagate to children (ADR-026 S2.2); error-channel fields **MUST NEVER** propagate (ADR-026 S2.4 — parent error isolation). `actor` is always `"agent"` for sub-agents, never `"user"` (ADR-025 R3). The meta-plan subgraph **NEVER** writes to vault or taskdog (ADR-013 planner-only).
- **`memory_prune.py`**: retention values **MUST** come from `algorithm_constants.json` + `load_constants._defensive_default`, never from Python `DEFAULT_MEMORY_*` constants. `memory_quarterly_strategies` is never pruned (SONHO-level artifacts). Pruning is inline prune-on-write, not a cron.
- **`checkpoint.py`**: `_DEFAULT_DB_FILENAME` and `_SCHEMA_VERSION` are drift-asserted literals; `schema_version` is monotonic and never reused (ADR-027 R9); `apply_retention` prunes only `ikigai_subgraph_links` (never the `ikigai_checkpoints` table).
- **`langchain_anthropic_shim.py`**: monkey-patch `anthropic.OverloadedError` **before any `langchain_anthropic` import** — otherwise `from langchain_anthropic import ChatAnthropic` raises `AttributeError` and every LLM call silently returns "0 suggestions". Do not upgrade `anthropic` (browser-use 0.13.10 pins 0.76.0) or downgrade `langchain-anthropic` (loses LangGraph 1.x). Removal plan tied to browser-use 0.13.10+.
- **`sse_publisher.py::_emit`** swallows every exception (`except Exception: pass`) — an SSE delivery failure never breaks the agent, but failures are invisible.
