## CONVENTIONS

- **Hyphenated package root**: `vibe-ops` is not a valid identifier — every `__init__.py` carries `# noqa: N999`; `pyproject.toml` adds `"src/__init__.py" = ["N999"]`.
- **Flat import root `src/`**: `mypy_path=["src"]`, `explicit_package_bases=true`, `namespace_packages=true`, `ignore_missing_imports=true`. Entry points manually patch `sys.path` (`period_sync_cli.py` inserts `vibe-ops/src`; `tests/*` insert `parents[2]/"src"`; `scripts/search_mesh.py` appends `../src`).
- **Two import styles coexist**: flat `from middleware.X import Y` (src-root) vs dotted `from .state import ...` / `from src.agents...`.
- **Two contract representations**: JSON Schema in `vibe-ops/contracts/*.json`, YAML frontmatter contract in `src/contracts/planning.v1.yaml`, Pydantic v2 models in `src/schemas/` and `src/contracts/*.py`.
- **Two schema registries with different shapes**: `src/contracts/registry.yaml` (keys `v1`, `contract_path` under `src/contracts/`) vs `schema_registry/registry.yaml` (semver keys `1.0.0`, `contracts/`, plus `slas`/`stats` blocks).
- **Pinned interpreter**: `requires-python = ">=3.11"` with the comment that it must match the CI matrix (uv would otherwise provision >=3.13 silently).
- **Lint/type**: ruff `line-length=100`, `target-version=py311`, select `E,F,W,I,N,UP,B,A,C4,PT,RUF`, ignore `E501`; per-file ignore `RUF002` for `src/pipeline/rice_exporter.py` (the `×` sign is intentional).
- **`--json` everywhere**: both argparse CLIs expose `--json` and emit a JSON envelope (`ok`, `command`, `ts`).
- **Idempotency contract**: `upstream_id` (12-char SHA-256 truncated) is mandatory on every sync rule (`SyncContractV1.validate_idempotency_chain`); `period_reports` sync re-runs as `skipped` (fixtures README: 6 ingested → 0 ingested/6 skipped).
- **Windows-first ops**: `.ps1` scripts + `task.bat` → `wsl -e task`; `run_loop.ps1` hardcodes `c:\Users\mathe\code_space\produtividade\life\vibe-ops`.
- **Language mix**: prose comments/docstrings are pt-BR, identifiers and code are English.
- **Fixture layout**: vault dirs are numerically prefixed (`2_projeto`, `3_indice`, `4_leitura`, `5_atomicas`); entity ids are prefixed (`proj_`, `dr_`, `atom_`, `moc_`, `lit_`, `tp_`, `sp_`, `rdm_`, `ja_`).
- **Rust TUI**: ratatui 0.26 + crossterm 0.27 + rusqlite 0.30 (`bundled`) + chrono/serde, edition 2021; reads a hardcoded `../vibe_ops.db`.
- **Duplicate dependency manifests**: `requirements.txt` (6 unpinned deps) coexists with `pyproject.toml` `[project].dependencies` + `[dependency-groups].dev`.
