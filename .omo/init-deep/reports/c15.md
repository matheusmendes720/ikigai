## CONVENTIONS

1. **Dual import trees, patch BOTH.** `src/` is on `PYTHONPATH` *and* the repo root is, so
   `src.mesh.adapters.taskdog` and `mesh.adapters.taskdog` are two distinct module objects.
   `tests/mesh/test_taskdog_cli.py`, `test_td_dep.py`, `test_td_note.py` all monkeypatch **both**
   module objects in the same fixture. (AGENTS.md: "When monkeypatching in tests, patch BOTH".)
2. **`from src.contracts.X` vs `from contracts.X` both appear** — e.g. `test_investigation_queue.py`
   imports `contracts.investigation`, `test_mcp_bridge_taskdog_battery.py` imports
   `contracts.task_change`, while 13 files import `src.contracts.task_change`. Same dual-tree rule.
3. **conftest owns `sys.path`**, not test modules: `tests/mesh/conftest.py` inserts repo-root `src/`
   at `sys.path[0]` (AGENTS.md: "`src/` on `PYTHONPATH` (set by `pytest.ini`)"). 21 root-suite files
   additionally do their own `sys.path` bootstrap (repo root, `src`, `src/ikigai/src`).
4. **Autouse isolation beats per-test setup**: `tests/mesh/conftest.py` redirects
   `src.mesh.queue.QUEUE_DIR` to a `tmp_path_factory` dir (Windows `PermissionError` fallback to
   `tempfile.mkdtemp` + `atexit` cleanup) and forces `TASKDOG_HTTP_ENABLED=0` so the HTTP-first
   taskdog path cannot shadow the SQLite fixture.
5. **Windows-aware subprocess plumbing**: `bufsize=0` on `subprocess.Popen` (JSON-RPC framing on
   Windows), hardcoded `src/ikigai/.venv/Scripts/python.exe` interpreter with `sys.executable`
   fallback, `timeout=30/60` on every `subprocess.run`, `cwd=REPO_ROOT`, `PYTHONPATH=REPO_ROOT`.
6. **Package layout asymmetry**: `tests/gateway/clients/` has `__init__.py` (so test modules import
   each other as `tests.gateway.clients.X`); `tests/mesh/` and `tests/mesh/adapters/` do not.
7. **Milestone-tagged filenames**: `test_m<NNN>_<feature>.py` (M4, M5, M84, M89, M98, M100, M101b,
   M105, M108, M109, M110, M112, M114a–f, M158/M158g, M163, M164, M190) — the number is the spec/milestone id.
8. **Docstrings are the spec contract**: every module docstring names the acceptance spec
   (`specs/M8-notification-channel/SPEC.md criterion #5`, ADR-014/033, R1.1–R1.5) and the
   "Run::" command. Guard tests carry their invariant id in the title (`Drift invariant (R1.3)`).
9. **`--json` is asserted** in 8 files — every CLI surface is expected to expose `--json`.
10. **Shell tests**: `#!/usr/bin/env bash` + `set -euo pipefail`, POSIX + Git Bash compatible,
    "pure shell, no Python deps"; they copy the target script into a temp dir so its
    `$(dirname "$0")/..` REPO_ROOT resolution lands on the temp dir, and stub binaries via
    `PATH` override + counter file (no network).
11. **Missing dependency ⇒ skip, never fail**: 27 `pytest.skip` calls; MCP servers/venv are optional
    (`skip_if_no_module`, `ikigai_python` skips when `src/ikigai/.venv` is absent).

## ANTI-PATTERNS

- **MUST NOT — forks touch `vault/`.** `tests/gateway/clients/test_vault_write_conformance.py`
  greps `src/solverforge_calendar` + `src/tuiboard` for `FORBIDDEN_PATTERNS`:
  `from\s+.*vault\s+import`, `import\s+.*vault`, `["']vault/`, `vault_read|vault_write`.
  `vault_write` (Layer-1 MCP in `src/ikigai/`) is the ONLY writer; forks must go through the tool.
- **MUST NOT — a second writer to `data/tasks.jsonl`.** `test_tasks_jsonl_single_writer_path.py`
  (R1.3) AST-scans every `.py` under `src/` and `sys_ikigai/` and flags `open()` with write modes
  `{w, a, wb, ab, w+, a+, r+, rb+, wb+, ab+}` or `Path.write_text/write_bytes` targeting `tasks.jsonl`.
  Allowlists: `CANONICAL_WRITERS = {src/mesh/adapters/cli.py}`,
  `CALLER_BRIDGE_FILES = {sys_ikigai/vault/task_io.py, src/ikigai/src/mcp_server/server.py}`
  (must *delegate*, never write directly), `READER_ALLOWLIST = {src/mesh/cli_cli.py,
  src/mesh/mesh_cli.py, src/tuiboard/aggregator.py, sys_ikigai/vault/task_io.py,
  src/mesh/adapters/cli.py}`. Any other module merely *mentioning* `tasks.jsonl` fails the test.
- **MUST — canonical writer uses atomic temp+rename** (`"with_suffix"` + `"os.replace"` present in
  `src/mesh/adapters/cli.py`), because R1.2's sidecar lock + R1.3's single-writer invariant assume it.
- **MUST — UEID regex byte-equal** across `src/contracts/common.py:_UEID_PATTERN` (compiled, canonical)
  and `sys_ikigai/entities/ueid.py:_UEID_PATTERN` (raw string). ADR-033 R1.5; drift = silent
  cross-fork join-key degradation. Guard test must keep passing if ADR-033 later flips the
  redeclaration into a re-export.
- **MUST handle MCP absence via `pytest.skip`** (spec §10, "verify-agent-fabricated-failures" lesson);
  never assert-fail because an optional module is missing.
- **MUST use a real subprocess + hand-rolled JSON-RPC** ("B5.B pattern"), not mocks, for fork MCP
  servers; "B6.4 lesson" = handle MCP absence.
- **NEVER — network calls during tests.** `test_notify.sh`: "NEVER invoked — no network calls during
  tests"; `curl` is stubbed via `PATH` override + counter file.
- **MUST NOT mutate the vault from an audit path** — `audit_drift()` is READ-ONLY
  (`test_vault_propagation.py`).
- **MUST NOT pollute `data/review_queue/`** — `test_review_queue_autoisolate.py` exists to "FAIL
  LOUDLY when isolation regresses" (it fails if the conftest `_isolate_review_queue` fixture is removed).
- **MUST NOT let the HTTP taskdog path shadow the SQLite fixture** (`TASKDOG_HTTP_ENABLED=0`).
- **Security invariant**: `tests/mesh/test_vault_read_path_traversal.py` mirrors `vault_write`'s
  path-traversal protection — `vault_read` is the read-side companion with the same security model.
