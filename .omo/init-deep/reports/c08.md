## CONVENTIONS

- **Contracts:** Pydantic v2 models are generally `frozen=True, extra="forbid"`, pure data containers, with UEID identity. `src/contracts/pyproject.toml` is a standalone Hatchling project (`pydantic>=2`, Python 3.11+, Ruff line length 100). `__all__` in the package is deliberately domain-grouped rather than alphabetical. Some contract modules omit the otherwise normal `from __future__ import annotations`.
- **Identifier drift:** `src/contracts/common.py` describes four-part UEID as canonical, but its runtime regex accepts short 4-part, long-UUID 4-part, and legacy 5-part forms; its own comment calls the 4-part form a read-only legacy alias. `vault_intent_extract.py` generates 5-part `tsk:intention:...` IDs. Treat these as intentional transition surfaces, not one settled format.
- **Skill contract:** a skill is a module with `SKILL_NAME`, `run_skill`, and proposal-producing `propose`; skills observe and propose but do not apply changes.
- **Graph/node contract:** nodes are plain `state -> dict` functions. `graph.py` wraps them in `_safe_node`, converting exceptions into `originating_node`/`error_type`/`error_message`/`traceback_str`. LangGraph factories use the mandated `(runtime, config)` signature, with `_build_*` internals for tests.
- **State contract:** `DynamicWorkflowState` uses `NotRequired` for every input/output field except reducer-backed `messages`, preserving Cloud Studio chat-input detection.
- **Import namespaces:** scoped code mixes bare `agents.v2...` imports with dotted `src.ikigai.src...` imports. Preserve each package’s established namespace; do not normalize globally.
- **Time:** contracts generally use naive UTC (`datetime.utcnow`), while reflection and graph code use timezone-aware UTC. These are mixed rather than unified.
- **Paperclip adapters:** Claude, Pi, Omo, and OpenClaw are real subprocess adapters; Hermes and MCode are deliberate `NotImplementedError` stubs. The adapter package docstring still says Pi/Omo/OpenClaw are stubs, so that doc is stale.
- **Dynamic graph MVP:** “dynamic” is a fixed three-slot sequential fan-out, not LangGraph `Send`/subgraph injection; planner, harness parser, subagent, and evaluator calls are deterministic mocks. `harness_builder._parse_spec_to_tasks` currently returns an empty list.
- **Tools drift:** `tools/views.py` documents `python -m tools.ikigai_views`, while the present module is `tools/views.py`. `vault_taskdog_sync.py` contains a hard-coded WSL taskdog path and derives `data/matheus` relative to `src/ikigai`; the 2026-08-26 backend report and older docs refer to the former `life-ops/ikigai` layout. Treat those paths/docs as historical or platform-specific.
- **Observability exception:** dual LangSmith/Langfuse export is an explicit opt-in exception to the normally local-only rule; absent credentials disable exporters. The backend deep-dive report is a dated 2026-08-26 diagnostic snapshot, not current architectural truth.

## ANTI-PATTERNS

- **NEVER execute a skill directly.** Skills emit pending `Proposal`s; changes apply only after human approval through the review queue. `propose()` must remain pure and must not write to disk.
- **NEVER bypass the review queue.** Every MCP write tool must call `_build_task_change` and therefore `_enqueue_task_change`; direct SQLite writes from MCP are forbidden. `taskdog_tag_list` is intentionally a read-only exception.
- **NEVER auto-apply reflection findings.** Reflection is observational memory; findings require human adjudication and are never used by the agent to choose its own policy.
- **NEVER delete investigations.** Their lifecycle is append-only transitions (`open -> in_progress -> resolved|archived`).
- **DO NOT implement QHE scoring or regime policy in this layer.** `QHEScore.qhe` and `regime_predicted` always raise `NotImplementedError` per ADR-013.
- **DO NOT fail a graph because an agent failed.** Real adapters return frozen `AgentResult(success=False, error=...)`; timeouts and missing CLIs are normal adapter failures. Stubs are the exception and raise `NotImplementedError`.
- **DO NOT auto-resolve merge conflicts.** Paperclip emits `MergeConflictError` for manual resolution. Cleanup failure is non-fatal and deliberately leaves the worktree for orphan-GC.
- **DO NOT make cost/time gates fail closed.** Cost and wall-clock gates are fail-open; the dangerous-content risk gate is fail-closed.
- **DO NOT let the dynamic planner emit zero tasks.** It always emits three roles; extras are warned and dropped, and a defensive fallback task protects the fan-out edge.
- **DO NOT stack the `sitecustomize` monkey-patch.** A module flag plus wrapper marker makes re-imports idempotent; explicit `html=False` must be preserved.
- **DO NOT commit `.env` or credentials.** Observability setup explicitly requires rotating an exposed key and keeping `.env` ignored.
- MCP tests must **skip**, not fail, when the SDK/server is absent; the async stdio module is currently skipped wholesale because `pytest-asyncio` is not configured.
- Planning docs prohibit LLM, NLP, embeddings, and non-arithmetic logic in daily/weekly pipelines and require append-only writes.
