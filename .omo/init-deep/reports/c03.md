## CONVENTIONS

- **`from __future__ import annotations` at the top of 19/20 modules** — `test_vault_write.py`
  is the lone exception (starts at `import hashlib`). `typing.Any` / `dict[str, Any]` used
  freely instead of `Dict`/`Optional`.
- **Manual `sys.path` bootstrap, per file, before any project import** (repo-root AGENTS.md
  calls this the "dual-tree identity"). Two shapes coexist:
  - *v2 node tests* (`test_v2_node_isolation*.py`, `test_v2_taskdog_nodes.py`,
    `test_v2_memory.py`, `test_v2_subagent_dispatch.py`, `test_v2_stateful_subgraph.py`,
    `test_v2_invoke_skill_taskdog.py`): insert `<repo>` and `<repo>/src` at position 0,
    then **append** `<repo>/src/ikigai/src` — appending (not inserting) is deliberate, so
    `src.ikigai.src.*` dotted imports still resolve.
  - *vault tests* (`test_vault_write.py`, `test_vault_sync.py`, `test_vault_sync_e2e.py`,
    `test_vault_write_audit_log.py`): `Path(__file__).resolve().parents[4]` → repo root only.
  Imports placed after the bootstrap carry `# noqa: E402`.
- **Two import dialects for the same v2 package, deliberately.** `src.ikigai.src.agents.v2.*`
  (dotted, repo-root-relative) in the node-isolation/taskdog files; bare `agents.v2.*`
  (resolving via the appended `src/ikigai/src` entry) in the memory/checkpoint/subgraph/prompt
  files. `test_v2_pav_intentions.py` documents the rule in its docstring: use
  `from agents.v2.prompts import ...`, *not* `from sys_ikigai.src.agents.v2.prompts import ...`.
  Monkeypatching must target **both** paths (AGENTS.md rule).
- **Heavy use of deferred (in-function) imports** — 216 deferred import statements vs 130
  module-level ones. Production modules are imported inside the test body so a broken
  import shows up as one failing test instead of a collection error.
- **`# ---` banner comments** separate fixture / AC / helper sections; docstrings carry the
  ADR clause they enforce (`"""ADR-027 R3: 4-segment thread_id"""`).
- **Fake-LLM mode** via `monkeypatch.setenv("IKIGAI_FAKE_LLM", "1")` (13 uses) and
  `IKIGAI_VAULT_ROOT` (9 uses) — no real LLM/Claude cost. `test_v2_prompt_chains.py`
  sets/clears `os.environ["IKIGAI_FAKE_LLM"]` manually around the whole module.
- **Isolation via `tmp_path`**, never the real `vault/` or `data/`: per-test
  `vault_root`, `memory_db`, `checkpoint_db`, `e2e_vault`, `cli_env` fixtures; `src.mesh.queue.QUEUE_DIR`
  and `sync_cli.{VAULT_ROOT,SYNC_STATE,REVERSE_SYNC_STATE,TASKDOG_DB,_build_adapter}` are
  monkeypatched to tmp paths.
- **`--json` on every CLI surface** (repo-wide rule): `sync/reverse/status/list/validate`
  each get a `--human` and a `--json` test; `--dry-run` is proven side-effect-free.
- **UEIDs are always canonical 4-part** (`^[a-z]{2,5}:[a-z0-9-]+:[a-f0-9-]+:[a-f0-9-]+$`,
  ADR-014); the 5-part form is asserted to be rejected.
- **`thread_id` canonical form** (ADR-027 R3): `actor-skill-cycle_short-sub_role`, e.g.
  `agent-weekly-2026-W36-parent`; sub-agent ids append `-subagent-<8hex>`.
  Because `cycle_short` may contain a dash, tests assert prefix/suffix, never a literal split.
- **Windows-aware assertions**: `test_vault_read.py` compares sha256 against
  `write_bytes` raw bytes because `write_text` converts `\n`→`\r\n`.
- `test_vault_read.py` is the only file with **no module-level `pytest` import** — it imports
  `pytest` inside each test body that needs `pytest.raises`.
- Class-based grouping only in `test_v2_taskdog_nodes.py` (4 `Test*` classes); every other
  file uses module-level functions. Helper classes are `_`-prefixed (`_TaskdogMock`,
  `_StubTaskdogAdapter`, `MockStdioAdapter`, `_CapturingMock`).

## ANTI-PATTERNS

Forbidden / asserted-absent inside this chunk:

- **Never auto-execute writes** (ADR-013): proposal nodes must emit a `proposal` dict to the
  review queue; `surface_intentions` "must NOT write to vault" (`test_v2_pav_intentions.py:75`).
- **Never write to SQLite directly from MCP** — every taskdog write tool must route through
  the mesh review queue (`_build_task_change`/`_enqueue_task_change` present, `apply_change`
  absent); "taskdog_tools.py must not import sqlite3" (`test_v2_multi_level_smoke.py:797`).
- **`vault_write` is the ONLY vault writer** (attribution §7). `test_vault_write_invariant.py`
  allowlists exactly: `sys_ikigai/vault/*` and `src/ikigai/src/mcp_server/tools_vault.py`.
  Any other file that opens a file for writing under a `vault/` path is a violation.
  Vault write path must be traversal-safe: absolute paths and `..` rejected.
- **`error_type` / `error_message` / `traceback_str` / `error_traceback` must NEVER reach a
  child** (ADR-026 S2.4); a child's failure must never set the parent's `error_type` (R5).
- **Planner-only (ADR-013)**: forbidden imports in `v2/prompts/`: `ikigai.core.scoring`,
  `ikigai.core.heuristics`, `ikigai.core`. Forbidden function defs in `tools_v2.py`:
  `compute_meta_vector`, `compute_qhe`, `compute_score`, `compute_regime`, `compute_phase`,
  `compute_passion_score`, `compute_skill_score`, `compute_market_score`,
  `compute_revenue_score`, `compute_course_score`, `compute_alignment_label`,
  `compute_weighted_priority`, `rank_tasks`, `classify_opportunity`, `apply_hysteresis`.
- **`IKIGAI_TOOLS` must contain exactly 12 entries** (counted by AST over the initial list
  *plus* `.extend([...])` calls) — `test_v2_prompt_chains.py:170`.
- **Node file size gate: each v2 node file < 200 LOC** — enforced against
  `tag_propagation.py`, `dep_graph.py`, `gantt_suggest.py` (`TestSizeGate`).
- **16-node graph**: `NODES` in `graph.py` must stay 16; `dispatch_sub_agents` is a
  subgraph and is intentionally *not* a node; `error` is a terminal counted in the 16.
- **M12 stub contract**: the 5 stub nodes (`balance`, `heuristics`, `plan`, `reflect`,
  `score_vectors`) must return the original node key as `None` + an `error_channel` list
  naming the deleted bridge wrapper + `last_step` = node name. Silently restoring a
  deleted bridge wrapper via try/except is the regression being guarded.
- **`--dry-run` must be side-effect-free**: no state file written, no `adapter.call_tool`,
  no `TaskChange` enqueued.
- **Audit log**: `.vault_audit.log` at the vault root (not next to the written file),
  append-only, format `{ISO-8601 UTC} actor={user|agent|system} path={vault_path}`.
  A failed write must NOT create an audit entry or the log file.
- **M12/stub + isolation rule, stated in-file**: "DO NOT modify node code; tests are
  read-only over node contracts" (`test_v2_node_isolation.py:23`,
  `test_v2_node_isolation_proposals.py:25`).
- **Memory layer is append-only**; no overwrites; pruning via `MEMORY_RETENTION_*` keys;
  `_migrate_v1_to_v2` must raise `NotImplementedError` (ADR-028 R11).
- **DRIFT NET floor**: the drift suite must stay green with **>= 60 passing** invariants
  (3 files state "66+ PASS / 2 SKIP"). `test_v2_multi_level_smoke.py` runs
  `test_canonical_scope.py` + `test_drift_detector.py` + `test_drift_extended_invariants.py`
  + `test_drift_state.py` in a subprocess and fails on any `" failed"` in the summary line.
- Per repo AGENTS.md, **drift tests are append-only** — never delete or weaken one; add a
  new case to `test_drift_extended_invariants.py` instead.
- **MCP tool-count assertions are deliberately floor-only, not exact** (`>= 15 @MCP.tool
  decorators`): the surface grows (M163/M164), so the test asserts the *safety property*
  (read-only trio ⊆ registered set, and the set is strictly larger) rather than a count.

## HOTSPOTS

- **> 500 raw lines (5 files)**: `test_v2_multi_level_smoke.py` 902, `test_v2_memory.py` 889,
  `test_v2_stateful_subgraph.py` 861, `test_vault_sync_cli.py` 758,
  `test_v2_subagent_dispatch.py` 627; `test_v2_invoke_skill_taskdog.py` 350 /
  `test_v2_taskdog_nodes.py` 386 are near the limit. All 5 are multi-ADR contract suites;
  the natural split point is the `# ---` banner sections (AC0/AC1/… per ADR rule).
- **`test_v2_multi_level_smoke.py`** is the heaviest single file: it composes 4 subsystems
  (sub-agent dispatch, stateful subgraph, memory layer, skill CLI) and shells out to the
  whole drift suite (`subprocess.run([sys.executable, "-m", "pytest", ...], timeout=300)`) —
  the only test here with a 5-minute-scale runtime.
- **Complexity concentration — `test_v2_stateful_subgraph.py`**: 4-thread concurrent-writer
  tests (`threading.Thread` × 4, `join(timeout=30)`), WAL/busy_timeout assertions, schema
  migration, retention, and 5 `build_thread_id`/`build_subagent_thread_id` validators.
  It is the heaviest concurrency surface in the chunk.
- **Highest fan-in symbols** (referenced from 2 scoped files each): `build_thread_id`,
  `build_subagent_thread_id`, `IkigaiCheckpointer`, `memory_init`, `memory_write`,
  `read_*_intentions|aggregations|syntheses|strategies`, `NODES`, `load_state`, `run_sync`,
  `vault_write`, and the 3 proposal nodes. Changing any of these breaks 2+ suites at once.
- **`test_vault_write.py:210-265`** is the only polling-based test in the chunk: it patches
  `vw.os.replace` to sleep 0.15 s and samples the target file size every 5 ms to prove
  no partial file is ever visible. Timing-dependent by construction — it is the most
  flaky-prone spot here.
- **Fixed sleeps** also in `test_vault_lock.py:31` (`time.sleep(0.01)` inside the
  critical section, by design) and `test_vault_write.py:225,239`.
- **`test_vault_sync_cli.py`** is the largest CLI surface: 27 tests over 5 subcommands
  (`sync`, `reverse`, `status`, `list`, `validate`) × {default, `--human`, `--json`,
  `--dry-run`}, plus a hand-written SQLite stub adapter (`_StubTaskdogAdapter`) that must
  mirror the real `call_tool` / `list_all` contract.
- **Duplicated helpers**: `_base_state()` is re-implemented in 4 files
  (`test_v2_node_isolation.py`, `..._proposals.py`, `..._smoke.py`) with slightly different
  key sets — a drift risk when `IKIGAiStateDict` fields change.
