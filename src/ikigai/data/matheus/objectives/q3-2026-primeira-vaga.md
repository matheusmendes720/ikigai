# TRIMESTRE — Q3-2026 primeira vaga remota

> **Janela:** 2026-07-06 → 2026-09-30 (90d, ~13 wd × 4 = 52 wd úteis).
> **Regime:** PUSH (budget hardwork 4.0h/dia, sleep target 7.5h, Q_HE target 0.85).

Este TRIMESTRE é o primeiro filho do SONHO `vaga-remota-2026`. Concentra o peso do ano
(70% do tempo alocado). Se Q3 não entregar os 4 KRs, Q4 vira catch-up — não dá para
relaxar aqui sem pagar juros em 2026-12-31.

## Key Results (OKRs)

### KR1 — Pipeline BI (W1)

**Meta:** 30 empresas-alvo mapeadas + 20 mensagens enviadas + 5 respostas em 90 dias.

- Mês 1 (jul): 10 empresas mapeadas, 7 mensagens, 2 respostas (warm-up).
- Mês 2 (ago): 12 empresas + 8 mensagens + 2 respostas (consolidação).
- Mês 3 (set): 8 empresas + 5 mensagens + 1 resposta (fechamento).

Decomposição em ONDAs Q3-1 (pipeline BI), Q3-2 (follow-up), Q3-3 (refinamento).

### KR2 — Portfolio (W2)

**Meta:** 1 demo interna de 12min gravada até 2026-09-15 + 1 projeto público no GitHub.

- 2026-08-15: storyboard da demo pronto.
- 2026-08-31: demo gravada (Loom + script + slides).
- 2026-09-15: demo publicada + 1 projeto público no GitHub (com README + data sample).

Decomposição em ONDAs Q3-2 (construção demo), Q3-3 (publicação + push inicial).

### KR3 — 1 processo seletivo técnico completo

**Meta:** fechar 1 processo seletivo técnico completo em empresa remote-first (phone screen
+ take-home + onsite loop). Não precisa fechar com oferta — precisa atravessar o loop inteiro
para validar o fit.

- Mês 1: 1 phone screen agendado.
- Mês 2: 1 take-home entregue.
- Mês 3: 1 onsite loop (3-5 entrevistas técnicas).

### KR4 — Q_HE ≥ 0.65 sustentado

**Meta:** manter Q_HE (composite de hábito + energia) ≥ 0.65 sem burnout por todo o trimestre.

- Daily check-in no journal.
- Weekly review domingo 18h.
- Se Q_HE < 0.45 por 4 dias seguidos → trigger para regime REDUCE (1.5h hardwork).
